## Features

### 1. Global SEO Settings
Set site-wide defaults from a single location inside the plugin.

- Site name
- Default logo
- Default social sharing image
- Robots.txt rules
- XML sitemap configuration
- Default meta settings

**How it works:** Global settings apply across all pages. Page-level settings override globals.

---

### 2. Page-Level SEO
Full meta control at the page level.

- Meta title with live character count
- Meta description with live character count
- Open Graph title, description, and image
- Twitter card fields
- Canonical URL setting
- Robots tag per page (index/noindex, follow/nofollow)
- AI generation for meta title and description

**AI Meta:** Uses AI credits to generate keyword-optimized meta titles and descriptions based on page content.

---

### 3. Schema Markup (JSON-LD)
Automatic schema generation and injection for any page type.

**Supported schema types:**
- Article
- TechArticle
- HowTo
- FAQPage
- Product
- LocalBusiness
- Organization
- WebSite
- BreadcrumbList

**How it works:**
- User selects page type and fills schema fields inside the plugin
- RankFrame generates the complete JSON-LD block
- Injects it as a single script tag on publish
- On republish, updates the existing script tag in place (no duplicate tags)
- One script tag. Always current. Zero duplicates.

---

### 4. Image SEO
Bulk image optimization across any Framer page.

- Scans all images on the current page
- Flags images with missing alt text
- Shows image file names and current alt text
- AI alt text generation in bulk using credits
- One-click apply to all flagged images

**How it works:** Works on Canvas pages. CMS image support separate.

---

### 5. 404 Monitor
Crawl and manage broken links without leaving Framer.

- Crawls the live Framer site
- Surfaces all 404 URLs
- Shows the broken path
- User sets redirect destination by typing the target slash path in the same tab
- Redirect is saved and applied
- No external redirect tool required

**404 URL input format:** Slash path only (example: /new-page-name). Not full URLs.

---

### 6. Page Speed
Google Lighthouse data pulled directly inside the plugin.

- Performance score per page
- Core Web Vitals: LCP, FID/INP, CLS
- Data pulled using Google Lighthouse API (not PageSpeed Insights)
- Per-page breakdown
- No third-party account required

---

### 7. Keyword Tracker
Google Search Console integration for keyword monitoring.

- Connect GSC account via OAuth
- See impressions, clicks, average position per keyword
- Per-page keyword data
- Keywords added manually by copy-pasting from GSC export
- No automatic keyword discovery (manual input workflow)

---

### 8. Submit for Indexing
Direct Google indexing submission from inside the plugin.

- Submit any Framer page for Google indexing
- Works without leaving the plugin
- Uses Google Indexing API or equivalent
- Instant submission, no external tool needed

---

### 9. AI Credits System
Powers all AI-driven features.

- AI meta title generation
- AI meta description generation
- AI alt text generation for images
- AI schema field suggestions
- Credits deducted per use
- Free credits included on signup
- Top-up available in dashboard

---

### 10. Minimized Mode
Plugin can be minimized to a compact state.

- Minimized mode shows Image SEO panel only
- Useful for staying in the design flow while running image scans
- Full plugin accessible on expand

---

### 11. Generate All
Bulk AI generation for meta across all pages.

- Generates meta title and description for all connected pages at once
- Stop button available to cancel mid-generation
- Uses AI credits

---

### 12. Recrawl
Recrawls the connected Framer site to refresh data.

- Trial: 2 recrawls maximum
- Paid plans: Unlimited recrawls
- Updates 404 data, image data, and page index
