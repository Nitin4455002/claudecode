Global SEO Settings Overview

Global SEO Settings is where you control your Framer site's site-wide SEO behavior. This article walks through the four tabs and explains when to use each one.

What Global SEO Settings does

Global SEO Settings is the first item in the RankFrame sidebar. It controls SEO behavior that applies across your entire Framer site by default.

Use it to set your default site-wide meta title and description, manage focus keywords, configure schema injection, and run the 404 monitor. Anything you set here applies to every page that does not have a per-page override.

The four tabs explained

B
Basic
Set your global site title and description. View the current live values side-by-side with AI-generated alternatives. Use the Write with AI button to generate fresh, keyword-rich copy based on your brand context.
K
Keywords
Manage focus keywords for any page on your Framer site. Toggle the focus keyword script on or off. Look up Search Volume, Difficulty (KD), Competition, and CPC for any keyword. Review keyword density across your homepage.
A
Advanced (Schema)
Inject JSON-LD structured data across your site. Build schemas manually or auto-generate them across your entire sitemap. Toggle the schema injection script on or off. Review and edit saved schemas.
4
404 Monitor
Track every 404 error on your site in real time. View URI, user agent, timestamp, and hit count. Add Exception Routes to whitelist intentional catch-all paths.

Global vs Per-Page Settings

RankFrame has two layers of SEO control: Global Settings and Per-Page Settings. Understanding when to use each one is the foundation of your workflow.

Setting Global Per-Page
Meta title and descriptionSite defaultOverride per page
Focus keywordSite-wide toggleAssigned per page via Target Page dropdown
Schema markupAuto-generated for all pagesEditable per page
Audit checksSite-wide scoreDetailed per-page audit

The general workflow is to set strong defaults in Global Settings, then customize specific high-priority pages in the Pages section.

Tip

Set your Global meta description to describe your brand and primary value proposition. Then override it on key landing pages with copy specific to that page's offer or topic.

When changes apply

Most changes save to RankFrame immediately. But changes only show on your live Framer site after you republish your project from Framer.

  • Meta title and description: Save in RankFrame, then republish your Framer site to apply.
  • Schema injection: Save your schema in RankFrame, click Save & Inject, then republish in Framer.
  • Focus keyword script: Toggle on in RankFrame, then republish in Framer.
  • 404 Monitor: Toggle on in RankFrame, then republish in Framer to add the tracking script to your live site.
Note

If you make significant changes to your Framer site (new pages, new images, restructured content), use Recrawl Website in the RankFrame sidebar so the plugin reflects the latest version of your site.

Frequently asked questions

What is the difference between Global Settings and Per-Page Settings?
Global Settings apply across your entire Framer site by default. Per-Page Settings, available in the Pages section, override the global values for individual pages. Use Global to set your defaults. Use Per-Page to fine-tune specific pages.
Do changes in Global Settings apply immediately to my live site?
Changes save immediately to RankFrame, but they only take effect on your live Framer site after you republish in Framer. Schema, focus keyword script, and 404 monitor scripts all require a republish to push to the live site.
How many tabs does Global SEO Settings have?
Four tabs: Basic, Keywords, Advanced (Schema), and 404 Monitor. Each tab handles a different area of site-wide SEO behavior.
Can I disable a Global setting for a specific page?
Yes. Open the Pages section, click the page you want to customize, and edit the meta tags, keyword assignment, or schema there. Per-page values override the global defaults.
