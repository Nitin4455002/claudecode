Managing Focus Keywords for Your Framer Site

Focus keywords tell RankFrame which terms each page is optimizing for. This article explains the Keywords tab, the Focus Keyword Script, and how to assign keywords to specific pages.

What a focus keyword is

A focus keyword is the primary search term you want a specific page to rank for on Google.

For example, your homepage might focus on "framer seo plugin" while your pricing page focuses on "framer seo plugin price" and your blog post about schema focuses on "framer schema markup."

RankFrame stores focus keywords per page. The Keywords tab in Global Settings is where you manage them.

The Focus Keyword Script toggle

At the top of the Keywords tab, you will see the Focus Keyword Script toggle.

When enabled, RankFrame injects a meta keyword tag on your live Framer site for each page that has a saved focus keyword. It also helps RankFrame's audit logic evaluate each page against its assigned keyword.

Toggle it on once. Republish your Framer site to push the script live. From then on, every saved focus keyword takes effect automatically.

Note

Google no longer uses the meta keywords tag as a ranking signal. The toggle still matters because RankFrame uses focus keywords for per-page audits, the Keyword Tracker, and AI-generated meta tags.

The Target Page dropdown

The Target Page dropdown lists every page from your sitemap. Select the page you want to assign a keyword to.

Common pages you will see:

  • / (your homepage)
  • /pricing
  • /about
  • /blog/[post-slug]
  • /projects/[project-slug]

Choose the page first, then add the keyword. Each keyword is bound to the selected page.

How to add a keyword

  1. 1
    Open Global Settings, Keywords tab
    Click Global Settings in the sidebar, then click the Keywords tab.
  2. 2
    Make sure Focus Keyword Script is on
    Toggle the Focus Keyword Script on if it is not already.
  3. 3
    Select the target page
    Use the Target Page dropdown to pick the page you want to assign the keyword to.
  4. 4
    Type your keyword
    Enter the keyword in the input field below the dropdown.
  5. 5
    Click Check to see metrics
    Click the Check button to view Search Volume, Difficulty (KD), Competition, and CPC for the keyword. See Understanding Keyword Metrics for details.
  6. 6
    Click Save
    Click Save to assign the keyword to the selected page. The keyword appears in the Saved Keywords list below.

Saved keywords list

All your assigned keywords appear in the Saved Keywords section. Each row shows:

  • The keyword text
  • Volume (search volume per month)
  • KD (keyword difficulty, shown in red if difficulty is high)
  • A delete (trash) icon to remove the keyword

Use Manage to edit your keyword list and Hide to collapse the section once you have what you need.

Tip

Sort and filter Saved Keywords by KD to spot easy wins. Keywords with high volume and low difficulty (KD under 30) are the best targets for new pages.

Best practices

One primary keyword per page

Pick one primary keyword per page. Adding ten different keywords to one page dilutes the page's relevance for any single one.

Match keyword to search intent

Make sure the keyword matches what users searching for that term actually want. A pricing page should target a "pricing" or "cost" keyword. A guide should target a "how to" keyword. A landing page should target a "[product] for [audience]" keyword.

Use long-tail keywords for new sites

If your domain is new, target longer, more specific keywords (e.g. "framer seo plugin for agencies" instead of just "seo plugin"). Lower competition means faster ranking.

Update keywords as your site evolves

If you change a page's content focus, update its focus keyword too. Stale keyword assignments confuse RankFrame's audits and tracking.

Frequently asked questions

What is a focus keyword in RankFrame?
A focus keyword is the primary search term you want a specific page to rank for. RankFrame stores focus keywords per page so you can track and optimize each page individually.
What does the Focus Keyword Script toggle do?
When enabled, RankFrame injects a meta keyword tag on your live site for each page with a saved focus keyword. It also helps the per-page audit evaluate each page against its assigned keyword.
How many focus keywords can I assign to one page?
You can save multiple keywords per page in RankFrame, but each page should have one primary focus keyword. Use additional keywords as secondary terms to track in the Keyword Tracker.
Do search engines still use the meta keywords tag?
Google does not use the meta keywords tag as a ranking signal. However, focus keywords still matter because RankFrame uses them for audits, tracking, and AI-generated meta tags.
Can I delete a saved keyword?
Yes. Click the trash icon next to any keyword in the Saved Keywords list to remove it. The keyword is removed from RankFrame immediately.
