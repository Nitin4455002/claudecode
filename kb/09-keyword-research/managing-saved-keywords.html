Managing Saved Keywords in RankFrame

Every keyword you save in RankFrame appears in the Saved Keywords list below the input field. This list lets you review what keywords are assigned to each page, spot high-difficulty keywords, and remove any that are no longer relevant.

1 Saved Keywords List

After saving at least one keyword, the header shows Saved Keywords (N) where N is the current count. Each row in the list displays three pieces of information: the keyword text, the Vol (search volume), and the KD (keyword difficulty) score. Rows appear in the order you saved them, with the most recent additions at the bottom.

This list is your at-a-glance record of every focus keyword you have committed to for the selected page. Review it before publishing to confirm your keyword strategy is still aligned with your content.

Saved Keywords list showing keyword text, Vol, and KD columns
2 Keyword Difficulty Badge (Red KD)

When the KD score is high (typically 50 or above), the KD badge turns red. This is a visual warning that the keyword is competitive. A red badge does not prevent saving, and it does not break any functionality. It signals that you should evaluate whether your site has the domain authority to rank for this term.

High KD keywords: A red KD badge means the top-ranking pages for this keyword are strong, established competitors. New or low-authority sites typically see better results targeting keywords with a KD below 30.
KD badge in red state on a high-difficulty keyword row
3 Manage and Hide Controls

The Saved Keywords header includes two controls: Hide and Manage. Hide collapses the list without deleting any keywords. Manage mode (when available) enables reordering or bulk actions on your saved keyword rows.

Use Hide to keep the plugin panel clean when you are focused on other sections of the Keywords tab. The list remains fully intact and all keywords stay assigned. Click the header again to expand the list when you need to review or edit it.

Saved Keywords header showing Hide and Manage controls
4 Deleting a Keyword

Each saved keyword row has a trash icon on the right side. Clicking the icon removes the keyword from the list and unassigns it from its page immediately. The deletion is not reversible through an undo action. If you remove a keyword by mistake, re-add it using the input field and the Check flow.

Once deleted, the keyword is no longer injected into the page meta tags, even if the Focus Keyword Script is still enabled. The change takes effect on the next Framer publish.

Tip: Before deleting, confirm which page the keyword is assigned to. Because the list does not display a page column, switch to the correct Target Page in the dropdown before making deletions.
Keyword row with trash icon highlighted on the right side
5 Keyword-to-Page Assignment

Each saved keyword is tied to the page that was active in the Target Page dropdown at the moment you saved it. There is currently no visible "page" column in the Saved Keywords list, so the assignment is implicit.

To keep your keyword organization clean, always confirm the correct Target Page is selected before saving a keyword. If you save a keyword while the wrong page is selected, delete it and re-save it with the correct page chosen.

Frequently Asked Questions

Q Can I assign the same keyword to multiple pages?
Each keyword save is tied to one Target Page selection. To assign the same keyword to two pages, save it twice: once with each page selected in the Target Page dropdown.
Q What happens to a deleted keyword on the live site?
If the Focus Keyword Script is enabled and you delete a keyword, the keyword will be removed from the meta keywords tag on the next Framer publish. Until then, the old tag may still be live on your published site.
Q Is there a limit to how many keywords I can save?
There is no documented hard limit. Keep the list focused: 2 to 5 keywords per page is a realistic and effective strategy for most Framer sites.
Q Can I edit a saved keyword without deleting it?
Currently there is no in-place edit option. Delete the keyword and re-add the corrected version using the input field and the Check flow.
Q Does hiding the Saved Keywords list affect injection?
No. Hide only collapses the display in the plugin panel. Saved keywords remain assigned and are still injected into your page meta tags when the Focus Keyword Script is enabled.
