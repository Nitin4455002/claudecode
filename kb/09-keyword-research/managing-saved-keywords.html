Managing Saved Keywords in RankFrame

Every keyword you save in RankFrame appears in the Saved Keywords list below the input field. This list lets you review what keywords are assigned to each page, spot high-difficulty keywords, and remove any that are no longer relevant.

1
Saved Keywords List
After saving at least one keyword, the header updates to show Saved Keywords (N), where N is the current count. Each row in the list displays three pieces of information: the keyword text, the Vol (search volume), and the KD (keyword difficulty) score. Rows appear in the order you saved them, with the most recently saved keyword at the bottom.
Saved Keywords list showing three rows with keyword text, Vol, and KD columns
2
Keyword Difficulty Badge (Red KD)
When the KD score is high (typically 50 or above), the KD badge turns red. This is a visual warning that the keyword is competitive. It does not prevent you from saving the keyword, but it signals you should consider whether your site has the domain authority to rank for it. Newer sites or pages with fewer backlinks may find high-KD keywords difficult to rank for in the short term.
Keyword row with a red KD badge showing a score of 68
Tip: If a keyword shows a red KD badge, search for 2-word or 3-word variations in the Keyword Analysis section. Longer phrases tend to carry lower difficulty scores and can be easier entry points for new or growing sites.
3
Manage and Hide Controls
The Saved Keywords header includes two controls on the right side: Hide and Manage. Clicking Hide collapses the entire list without deleting any keywords. This is useful when you want to keep the plugin panel tidy while working on other tab sections. Clicking Manage (when active) opens bulk-action mode, which lets you reorder or act on multiple keywords at once. The list and all keyword assignments remain intact regardless of which view state you are in.
Saved Keywords header with Hide and Manage controls highlighted
4
Deleting a Keyword
Each saved keyword row has a trash icon on the right side. Click the icon to remove the keyword from the list and unassign it from its page. Once deleted, the keyword is no longer injected into the meta keywords tag, even if the Focus Keyword Script is still enabled. Deletion is immediate and there is no confirmation prompt. If you remove a keyword by mistake, re-add it using the input field above the list and run the Check flow again.
Keyword row with the trash icon visible on the right side
Important: Deleting a keyword in the plugin does not update your live Framer site until you publish. If the Focus Keyword Script is active, the deleted keyword will remain in the live meta keywords tag until your next Framer publish.
5
Keyword-to-Page Assignment
Each saved keyword is tied to the page that was active in the Target Page dropdown at the moment you clicked Save. The Saved Keywords list does not currently display a page column, so the visible list does not tell you which keyword belongs to which page. To keep your assignments accurate, always confirm the correct Target Page is selected before saving a new keyword. If you need to audit assignments, switch the Target Page dropdown to each page and check which keywords appear in the list.
Target Page dropdown open with a page selected before saving a keyword

Keeping Your Saved Keywords Organized

A clean keyword list makes it easier to understand your SEO strategy at a glance. Here are a few practical habits that help:

  • Save 2 to 5 keywords per page. More than that dilutes your focus and makes it harder to write content that genuinely targets a specific phrase.
  • Before saving a keyword, check the KD badge. If it is red, decide whether to keep it, find a lower-competition alternative, or accept a longer ranking timeline.
  • Use the Hide control when you are working on other plugin sections. It keeps the interface clean without affecting any data.
  • Review and prune your saved keywords after major site restructures. Deleted pages may still have keywords assigned: remove those orphaned keywords to keep the list current.

Frequently Asked Questions

Can I assign the same keyword to multiple pages? ▼
Each keyword save is tied to one Target Page selection. To assign the same keyword to two pages, save it twice: once with each page selected in the Target Page dropdown. Both saves will appear in the list and each will inject independently when its respective page is published.
What happens to a deleted keyword on the live site? ▼
If the Focus Keyword Script is enabled and you delete a keyword, the keyword will be removed from the meta keywords tag on the next Framer publish. Until then, the old tag may still be live. If accurate meta tags are critical for your campaign, publish your Framer site promptly after deleting.
Is there a limit to how many keywords I can save? ▼
There is no documented hard limit. Keep the list focused: 2 to 5 keywords per page is a realistic and effective strategy. A very long keyword list often indicates a lack of clear topical focus, which can hurt rather than help your rankings.
Can I edit a saved keyword without deleting it? ▼
Currently there is no in-place edit option. Delete the keyword using the trash icon and re-add the corrected version using the input field and Check flow. This takes only a few seconds and ensures the keyword data (volume, difficulty) is freshly fetched.
Does hiding the Saved Keywords list affect injection? ▼
No. Hide only collapses the display in the plugin panel. Saved keywords remain assigned to their pages and are still injected into the meta keywords tag when the Focus Keyword Script is enabled. The Hide control is a display preference only.
