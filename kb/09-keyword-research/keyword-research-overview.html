Keyword Research

Keyword Research Overview

The Keywords tab in Global Settings is your keyword research hub inside RankFrame. Here you assign focus keywords to specific pages, check search metrics like search volume and keyword difficulty, and analyze how keywords appear across your site content. All of this happens without leaving the Framer plugin panel.

How to Open the Keywords Tab

1 Open Global Settings
Click the gear icon in the left sidebar of the RankFrame plugin panel to open Global Settings. This panel controls site-wide SEO configuration, including keyword research.
Global Settings panel with gear icon highlighted in the RankFrame left sidebar
2 Select the Keywords Tab
At the top of Global Settings you will see four tabs: Basic, Keywords, Advanced, and 404 Monitor. Click Keywords to open the keyword research workspace.
Global Settings tab bar with Keywords tab selected

Focus Keyword Script Toggle

3 Focus Keyword Script Toggle
The on/off toggle at the top of the Keywords tab controls whether RankFrame injects your saved keywords into the live site. When turned on, RankFrame inserts the saved keywords into a meta keywords tag on each assigned page during the next site publish. Turn this off if you prefer not to expose keyword data in the page HTML.
Focus Keyword Script toggle in the on state at the top of the Keywords tab
Note: The meta keywords tag has minimal direct ranking impact in modern search engines, but it can signal topic relevance to some crawlers and analytics tools.

Target Page Selector

4 Target Page Dropdown
The Target Page dropdown lists every page from your sitemap. Examples include /, /thoughts, /projects/rkg, and /projects/ember-and-bloom. Select the page you want to assign a keyword to before checking or saving. Each keyword is bound to the page active in this dropdown at the time you click Save.
Target Page dropdown open showing a list of site pages from the sitemap

Keyword Input and Check

5 Keyword Input Field and Check Button
Type a focus keyword in the input field, then click Check. RankFrame queries its integrated data provider and returns four metric cards below the input: Search Vol, Difficulty (KD), Competition, and CPC. The Check action is free and does not consume AI credits.
Keyword input field with a typed keyword and the four metric cards populated below

Saved Keywords List

6 Saved Keywords Section
Keywords you have saved appear in the Saved Keywords (N) section below the input area. The count in parentheses reflects the number of saved keywords for the currently selected page. Each row shows the keyword text along with its Vol and KD values. Keywords with high difficulty display a red KD badge as a caution indicator. Every keyword row includes a delete (trash) icon to remove it from the list.
Saved Keywords list showing multiple keywords, Vol and KD badges, and a red KD badge on a high-difficulty keyword

Keyword Analysis

7 Keyword Analysis Panel
Below the Saved Keywords list is a collapsible Keyword Analysis section. Click Show details to expand it or Hide details to collapse it. In its collapsed state it shows three aggregate values: Total Keywords, Avg Density, and Total Frequency. Expanding the panel reveals the full Keyword Details table, which includes a word-count filter and a search field so you can find specific terms quickly.
Keyword Analysis panel expanded, showing the details table with filter and search controls
Tip: Use Avg Density to confirm your focus keywords appear naturally throughout your page content. Very low density may mean you need to work the keyword into your copy more organically. Very high density risks looking spammy to search engines.

Frequently Asked Questions

What does the Focus Keyword Script toggle do?
When enabled, RankFrame injects saved keywords into a meta keywords tag on each assigned page during the next Framer publish. This signals the page topic to search crawlers.
How many keywords can I assign to a page?
You can assign multiple focus keywords to the same page. Each appears as a separate row in the Saved Keywords list.
Does checking a keyword cost credits?
No. Checking keyword metrics (Search Vol, KD, Competition, CPC) is free and does not use AI credits. Credits are only used for AI content generation.
Where do the search volume and keyword difficulty numbers come from?
RankFrame pulls keyword metrics from its integrated data provider when you click Check. The data reflects global search estimates.
Can I assign different keywords to different pages?
Yes. Use the Target Page dropdown to select a specific page before saving. Each keyword is bound to the page you selected.
