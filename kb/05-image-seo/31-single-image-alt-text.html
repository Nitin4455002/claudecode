Single Image Alt Text: Cards, Wand Icon, and the Alt Text Field

Every image in the Image SEO grid appears as a card. This article walks through each part of the card: the checkbox, thumbnail, label, wand icon for single-image AI generation, and the editable alt text input field.

Card anatomy overview

The right panel of Image SEO displays your images as a grid of cards. Each card represents one image and contains all the information and controls needed to review and update its alt text without leaving the panel.

A card is structured in two rows:

  • Card header row: contains the checkbox (left), the thumbnail, the image label, and the wand icon (right).
  • Input row: a full-width alt text field that spans the entire width of the card below the header.

The red dot overlay on the thumbnail is a quick visual signal. If you see a red dot, the image has no alt text saved. Once alt text is added and saved, the dot is removed.

Tip

Scan the grid visually for red dots to quickly identify which images still need attention. Images without red dots are already covered.

1
Checkbox
Image card showing checkbox at the left of the card header row

The checkbox sits at the far left of the card header row. Checking it selects that image for bulk actions. You can check multiple cards and then use the bulk controls (such as bulk AI generation) to process all selected images at once.

Checking the checkbox does not trigger any immediate action on its own. It simply marks the image as part of the current selection. A header-level "select all" control (when visible) checks all cards in the current view simultaneously.

  • Use checkboxes when you want to generate alt text for a specific subset of images, not necessarily all of them.
  • Deselect a card by clicking its checkbox again.
  • Switching Explorer nodes clears the current selection.
Tip

To process only images missing alt text, filter the grid first (for example by using the Explorer or search), then select all and run bulk generation on the filtered set.

2
Thumbnail and red dot indicator
Image thumbnail with a red dot in the corner indicating missing alt text

The thumbnail is a small preview of the image rendered directly inside the card. It gives you a visual reference so you can confirm you are writing alt text for the correct image before you type or generate anything.

A red dot appears in the corner of the thumbnail when the image has no alt text saved. The red dot works as an at-a-glance audit indicator across the entire grid. Once you save alt text for the image (either typed manually or generated by AI), the red dot is removed.

  • Red dot present: alt text is missing. Action required.
  • No red dot: alt text has been saved. No action needed unless you want to update the copy.
Note

The red dot reflects the saved state of the alt text, not the current content of the input field. If you type into the field but do not save, the red dot remains until the value is confirmed.

3
Image label
Image label showing "Canvas Image" or CMS collection path like "Our Cases >"

The image label sits between the thumbnail and the wand icon in the card header. It tells you where the image comes from so you can write appropriately targeted alt text.

The label takes one of two forms depending on the image source:

  • Canvas Image: shown when the image is placed directly on a Framer canvas page rather than coming from a CMS collection.
  • CMS collection path: shown as the file name (for example, 01) with the collection name as context (for example, Our Cases >). This tells you exactly which CMS collection the image belongs to.

Reading the label before writing alt text helps you tailor the description. For example, an image in the Our Cases collection is likely a case study visual, which calls for different alt text than a generic Canvas Image used as a decorative hero graphic.

4
Wand icon (single AI generation, uses 1 credit)
Wand icon at the right side of the card header, triggering single-image AI generation

The wand icon sits at the right end of the card header row. Clicking it sends the image to RankFrame's AI model, which analyzes the visual content and writes a descriptive alt text string. The result is filled directly into the alt text input field below.

Each click of the wand icon uses exactly 1 credit, regardless of the image size or content. The wand icon is the per-card equivalent of bulk generation and is useful when you want to generate for just one specific image rather than a batch.

  • The wand icon generates alt text for that card only.
  • Generation consumes 1 credit per click.
  • The result is placed in the alt text field but is not saved automatically. Review and confirm before saving.
  • You can click the wand icon again to regenerate if you are not satisfied with the first result (uses another credit).
Note

Credits are consumed at the point of generation, not at the point of saving. If you regenerate multiple times for the same image, each generation costs 1 credit.

Tip

Use the wand icon for images that need a custom review before saving. This is especially useful for images that contain brand names, product identifiers, or text overlay where you want to confirm the AI has read the content correctly.

5
Alt text input field
Full-width alt text input field below the card header, pre-filled or showing "Alt text..." placeholder

The alt text input field spans the full width of the card below the header row. It is a standard text input that accepts any string. You can type, paste, or edit alt text here at any time, with or without using the wand icon.

The field has two starting states:

  • Pre-filled: if the image already has saved alt text, that text appears in the field when the card loads. The red dot is absent.
  • Empty with placeholder: if no alt text has been saved yet, the field shows the placeholder text Alt text... in grey. The red dot is present on the thumbnail.

After the wand icon runs AI generation, the generated text is inserted into this field. You can then edit it freely before saving. If you prefer not to use AI at all, simply click into the field and type your own alt text directly. No credits are used for manual input.

Writing good alt text

Good alt text is concise, descriptive, and relevant to the surrounding page content. A few guidelines:

  • Describe the image as you would to someone who cannot see it.
  • Include relevant keywords naturally, but do not stuff keywords into every image.
  • Avoid starting with "Image of" or "Photo of". Screen readers already announce the element as an image.
  • For purely decorative images, an empty alt attribute is correct. Use the input field to clear any existing value.
  • Keep descriptions to roughly 80 to 125 characters for most images.
Tip

For CMS images that appear on multiple pages (for example, a service thumbnail that reappears across case studies), write alt text that describes the image itself rather than a specific page context. This keeps the description accurate wherever the image appears.

Writing alt text: AI vs. manual

RankFrame supports two ways to populate the alt text field for a single image. They can be mixed freely across your image set.

Option A: AI generation (wand icon)

  1. 1
    Locate the image card
    Use the Explorer tree or search field to find the image you want to update.
  2. 2
    Click the wand icon
    The icon is at the right end of the card header. One credit is consumed and AI generation begins.
  3. 3
    Review the generated text
    The result appears in the alt text input. Read it carefully to confirm it is accurate and on-brand.
  4. 4
    Edit if needed and save
    Click into the field, make any edits, then confirm. The red dot on the thumbnail will clear once the value is saved.

Option B: Manual input

  1. 1
    Click into the alt text input field
    The field is ready for typing immediately. No button press is required to activate it.
  2. 2
    Type or paste your alt text
    Write a clear, concise description of the image. No credits are used.
  3. 3
    Save
    Confirm the value. The red dot disappears once the alt text is saved successfully.

Frequently asked questions

How many credits does generating alt text for one image cost?
One AI generation costs 1 credit. Each time you click the wand icon on a single image card, RankFrame uses your AI model to analyze the image and write alt text, consuming exactly 1 credit regardless of the image size or content.
What does the red dot on an image thumbnail mean?
A red dot in the corner of the thumbnail is a visual indicator that the image currently has no alt text saved. Once you add or generate alt text and save it, the red dot disappears, confirming the image is no longer missing an alt attribute.
Can I edit the AI-generated alt text after it is filled in?
Yes. After the wand icon fills the alt text input, you can click into the field and edit the text freely before saving. The input behaves like a standard text field, so you can refine the generated copy, add brand-specific context, or replace it entirely with your own wording.
What is the difference between the wand icon and bulk AI generation?
The wand icon on a single card generates alt text for that one image only, using 1 credit. Bulk AI generation lets you select multiple images using their checkboxes and generate alt text for all of them in one action, using 1 credit per image.
Do I have to use AI to add alt text, or can I type it manually?
You can type or paste alt text directly into the input field at any time without using the wand icon. No credits are consumed when you write alt text manually. This is useful for images where you already know the exact description you want or where custom branding language is important.
