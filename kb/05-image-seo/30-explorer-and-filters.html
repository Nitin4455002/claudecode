Image SEO Explorer and Filters

The Explorer is the left panel inside Image SEO. It gives you a tree-based view of every image on your Framer site, organized by source, so you can quickly scope the image grid to exactly what you need to audit or fix.

Section overview

When you open Image SEO in RankFrame, the screen splits into two panels. The left panel is the Explorer. The right panel is the image grid, which reacts to whatever you select in the Explorer. Above both panels sits a controls row with the site selector, search field, refresh button, and export button.

The Explorer organizes your images into a two-level tree:

  • All Images: the root node showing the total count across your entire site (for example, 517 images)
  • Canvas: static images placed directly on Framer canvas pages (for example, 428 images)
  • CMS: images sourced from CMS collections (for example, 89 images), expandable to reveal one sub-folder per collection

CMS sub-folders carry the collection name and count. For example: Our Cases (33), Our Service (29), Thoughts (8), Work (19). Clicking any node instantly filters the image grid on the right to show only images from that location.

Tip

Start at All Images to get a site-wide picture of how many images are missing alt text, then drill into individual collections to prioritize the highest-traffic pages first.

1
Explorer tree
Explorer tree showing All Images, Canvas, CMS, and CMS sub-folders

The tree renders three levels: the root All Images node, the Canvas branch, and the CMS branch. Clicking CMS expands it to reveal one sub-folder per collection. Each node shows a count badge so you can immediately see how many images live in that location.

Selecting a node is the primary way to scope the image grid. Only one node can be active at a time. To return to the full site view, click All Images again.

  • Clicking All Images shows every image on the site.
  • Clicking Canvas shows only static canvas images.
  • Clicking CMS shows all CMS images combined.
  • Clicking a CMS sub-folder (for example, Our Cases) shows only that collection's images.
Note

The counts shown in the Explorer reflect the last time data was fetched. If you have published new images recently, click Refresh to update the counts.

2
Site selector
Site selector pill showing gear icon and site name "7 Seers"

The site selector appears at the left of the controls row as a fully rounded pill. It displays a gear icon followed by the active site name (for example, 7 Seers). Click the pill to open a dropdown and switch to a different site connected to your RankFrame account.

All Explorer counts, the image grid, and any search results update immediately to reflect the newly selected site. This is useful when you manage multiple Framer projects under one RankFrame account and need to switch between them without leaving the Image SEO section.

3
Search field
Search field with magnifier icon and "Search..." placeholder

The search field sits in the controls row between the site selector and the refresh button. It carries a magnifier icon and a Search... placeholder. Type any characters to filter the image grid in real time.

Search matches against two attributes of each image:

  • Filename: the file name of the image asset as stored in Framer.
  • Alt text: any alt text already saved for that image.

The Explorer node you have selected continues to act as a scope. For example, if you have Our Cases selected and then type in the search field, results are filtered to filenames and alt text within that collection only. Clear the search field to restore the full view for the active node.

Tip

Search for Alt text... (the placeholder text) to find all images that have no alt text saved yet. This works if the empty placeholder is stored as the field value.

4
Refresh button
Refresh button with circular arrows icon

The refresh button (circular arrows icon) re-fetches image data from your Framer site. Click it any time you have published changes to your site and want the Explorer and image grid to reflect the latest content.

Common situations that call for a refresh:

  • You have added new images to canvas pages or CMS collections and published the site.
  • You have deleted images and want the counts to update.
  • Counts in the Explorer do not match what you see live on your Framer site.
Note

The refresh re-fetches image metadata only. Alt text you have already saved through RankFrame is not affected or overwritten.

5
Export button (CSV)
Purple Export button with download icon

The export button is styled in purple with a download icon and sits at the right end of the controls row. Clicking it downloads a CSV file containing data for all images currently in scope. The CSV includes each image's filename, source path, and saved alt text.

The export reflects the current Explorer selection and any active search filter. For example, if you have Our Cases selected in the Explorer, the CSV contains only images from that collection. Select All Images before exporting to get a full site-wide report.

  • Use the CSV to share an image audit with clients or team members.
  • Import the CSV into a spreadsheet to track alt text completion over time.
  • Use it as a backup of all saved alt text before making bulk changes.
Tip

Export before and after a bulk AI generation session so you have a record of what changed and can review the generated alt text outside of the plugin.

Typical workflow

Here is a recommended sequence for auditing image alt text on a new site:

  1. 1
    Select your site
    Use the site selector pill to confirm you are working on the correct Framer project.
  2. 2
    Refresh to get the latest data
    Click the circular arrows icon to ensure the Explorer counts and image grid are current.
  3. 3
    Click All Images and export a baseline CSV
    Download a CSV of the full site so you have a record of the starting state before you add any alt text.
  4. 4
    Drill into Canvas or a CMS collection
    Click the Explorer node for the section you want to work on. The image grid narrows to that scope.
  5. 5
    Search to find images missing alt text
    Use the search field to locate specific images by name if you already know which ones need attention.
  6. 6
    Add or generate alt text, then export again
    After completing a section, export another CSV to track progress. Repeat for each Explorer node.

Frequently asked questions

What is the Image SEO Explorer in RankFrame?
The Explorer is the left panel inside the Image SEO section of RankFrame. It displays a two-level tree of all images on your site, organized into Canvas images and CMS collection sub-folders. Clicking any node filters the image grid on the right to show only images from that location.
How do I filter images by CMS collection?
Expand the CMS node in the Explorer tree by clicking it. Sub-folders appear for each of your CMS collections (for example, Our Cases, Our Service, Thoughts, Work). Click any sub-folder to filter the image grid to that collection only.
Can I search for a specific image by name or alt text?
Yes. Use the Search field in the controls row at the top of the section. Type any part of the filename or existing alt text and the image grid updates immediately to show only matching images.
What does the Export button download?
The Export button (purple, with a download icon) generates a CSV file containing data for all images currently in view, including filenames, source paths, and any alt text that has been saved. This is useful for auditing or sharing image SEO status with a team.
When should I use the Refresh button?
Click Refresh (the circular arrows icon) after publishing changes to your Framer site or after adding new images or CMS entries. This re-fetches the latest image data so the Explorer counts and grid reflect your current site content.
