Minimized Mode: Full-Width Image Grid

Collapse the plugin sidebar in one click to give the Image SEO grid the full panel width -- ideal for sites with hundreds of images that need bulk alt text work.

RankFrame's Image SEO panel shares the plugin window with a left sidebar containing the navigation, SEO score widget, and your account block. Minimized Mode hides all of that so the image grid can spread across the full available width -- letting you see and act on far more images at once.

1
Expand/Collapse arrows icon

The expand/collapse arrows icon is located in the top-right corner of the Image SEO header. It is the only control that toggles Minimized Mode. There is no settings menu, keyboard shortcut, or alternative way to activate it -- just click the icon.

Arrows icon in the top-right of the Image SEO header
Tip

The icon is small but always visible in the header row, even when you scroll down through the image grid.

2
Minimized state

When Minimized Mode is on, the outer plugin left sidebar collapses completely. This hides the navigation tabs, the SEO score widget, and the user account block. The Image SEO panel expands to fill the freed space, giving the image grid significantly more horizontal room. On sites with hundreds of images this makes bulk review much faster.

Plugin in Minimized Mode -- full-width image grid, sidebar hidden
Note

While in Minimized Mode you cannot navigate to other sections of the plugin. The navigation is hidden. Click the arrows icon again to restore it.

3
Standard state

When Minimized Mode is off, the plugin returns to its normal two-column layout: the left sidebar with navigation and widgets on the left, and the Image SEO panel on the right. Click the arrows icon a second time to return to this view at any point.

Plugin in standard state -- sidebar visible alongside image grid
Tip

Minimized Mode is a view toggle, not a persistent setting. It resets each time you reload the plugin, so your navigation is always a single click away when you return.

How to toggle Minimized Mode

  • 1
    Open the Image SEO panel
    Launch RankFrame inside Framer and click Image SEO in the left navigation.
  • 2
    Locate the arrows icon
    Find the expand/collapse arrows icon in the top-right corner of the Image SEO header row.
  • 3
    Click the icon to enter Minimized Mode
    The left sidebar collapses instantly and the image grid expands to full width.
  • 4
    Click the icon again to return to standard view
    The sidebar reappears and the layout returns to the default two-column view.

Frequently asked questions

Where is the toggle for Minimized Mode?
The expand/collapse arrows icon is in the top-right corner of the Image SEO header. Clicking it once enters Minimized Mode; clicking it again returns to standard view.
What exactly gets hidden in Minimized Mode?
The entire left sidebar collapses -- this includes the plugin navigation tabs, the SEO score widget, and the user account block. Only the Image SEO panel itself remains visible, at full width.
Is Minimized Mode saved as a setting?
No. It is a temporary view toggle, not a persistent setting. It resets each time you reload the plugin.
Can I still navigate to other plugin sections in Minimized Mode?
No. The left navigation is hidden while Minimized Mode is active. Click the arrows icon again to restore the sidebar and return to full navigation.
When is Minimized Mode most useful?
It is most useful during large bulk operations on sites with hundreds of images, where seeing more image thumbnails at once speeds up the review and editing workflow significantly.
