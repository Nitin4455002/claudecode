Global Alt Text Suffix

Set a suffix once and RankFrame appends it to every AI-generated alt text across your entire site. One field, consistent branding, zero repetition.

Overview

The global suffix is a short piece of text that RankFrame automatically appends to the end of every alt text it generates with AI. You set it once in your Image SEO settings and it applies to all future AI generations across the entire site.

Common uses include adding a studio or photographer name, a photo type label, or a platform identifier. For example, setting the suffix to "by Meridian Studio" means every generated alt text will end with that phrase, giving every image a consistent brand signal without any manual effort.

Tip

Use the global suffix alongside bulk alt text generation to brand an entire site's image library in a single session.

How it works

When you run AI alt text generation, RankFrame composes a description of the image and then joins your suffix to the end of that description before saving. The suffix is appended automatically during generation; you do not need to type it into each alt text field manually.

The suffix has no effect on alt text you have written by hand. It only applies to text produced by the AI generator, so your intentional manual edits are always preserved as-is.

  • 1
    Open Image SEO settings in RankFrame
    Navigate to the Image SEO section of the plugin and locate the global suffix field, usually at the top of the settings area.
  • 2
    Type your suffix into the input field
    Enter the text you want appended to every generated alt text. Keep it short and descriptive. For example: by Studio Name or Framer portfolio image.
  • 3
    Save the setting
    Once saved, the suffix is active for all future AI-generated alt text on this site. No further action is needed.
  • 4
    Run AI generation as normal
    Use single-image generation or bulk generation. RankFrame automatically appends the suffix to every result. You will see it in the alt text field after generation completes.

Field reference

1
Suffix input field

A plain text input where you type the phrase you want appended to every AI-generated alt text. There is no character limit enforced by the interface, but shorter suffixes are more practical. Example values: by Studio Name, high-resolution photo, Framer portfolio image.

Suffix input field in the Image SEO settings panel
2
How the suffix applies

The suffix is appended automatically during AI generation. You do not need to type it into individual alt text fields. After clicking Generate Alt Text, the finished result in each card's input field will already include the suffix at the end. You can edit the combined text if needed before saving.

Tip

Review a few generated results after setting a new suffix to confirm spacing and punctuation look right. A leading space before the suffix text is handled automatically, but double-check before running a large bulk generation job.

3
When the suffix applies

The suffix applies only to AI-generated alt text. Alt text you have typed manually in any image card is never modified by the suffix setting. This means you can freely mix AI-generated and manually written alt text on the same site without worrying about the suffix corrupting your hand-crafted descriptions.

Note

The suffix is not applied retroactively. Alt text generated before you set the suffix will not be updated. To add the suffix to existing generated alt text, select those images and run generation again.

Using it as an agency

The global suffix is a per-site setting, which makes it ideal for agencies managing multiple Framer projects. You can set a different suffix for each client site to reflect their individual brand identity.

A typical agency workflow:

  1. Open the client's Framer project in RankFrame.
  2. Set the global suffix to the client's studio name or preferred phrase.
  3. Run bulk alt text generation across all images.
  4. Every generated alt text ends with the client's brand phrase automatically.
  5. Switch to the next client project and set a different suffix.

This approach eliminates the need to manually add branding to each alt text field, which can represent a significant time saving when a single site has hundreds of images.

Tip

Keep a shared doc with your preferred suffix text for each client so you can paste it in quickly when starting a new project or revisiting an existing one.

Frequently asked questions

Does the global suffix change alt text I have already written by hand?
No. The global suffix only applies to alt text generated by RankFrame's AI. Any alt text you have typed manually remains exactly as you wrote it.
What are some good examples of a global suffix?
Common examples include "by Studio Name", "high-resolution photo", and "Framer portfolio image". The best suffix is short, descriptive, and consistent with how your brand or agency wants images labeled across the site.
Can I remove the suffix after it has been applied?
You can clear the suffix field at any time. Doing so stops it from being appended to future AI-generated alt text. Previously generated alt text that already includes the suffix would need to be edited individually to remove it.
Is the global suffix applied retroactively to existing alt text?
No. The suffix is appended during AI generation. Alt text generated before you set the suffix will not be updated automatically. Run bulk generation again on those images if you want the suffix added.
Can agencies use a different suffix for each client site?
Yes. The global suffix is a per-site setting. Each Framer project managed through RankFrame has its own suffix field, so you can set a different brand suffix for every client site you manage.
