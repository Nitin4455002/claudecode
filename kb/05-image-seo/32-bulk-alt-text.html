Overview

Writing descriptive alt text for every image is one of the highest-impact on-page SEO tasks you can do, and it is also one of the most tedious. RankFrame's bulk generation feature removes that friction entirely. Instead of opening each image one by one, you select all images on the current page of the grid in a single click, hit Generate Alt Text, and the AI fills every field automatically.

After generation you can review, tweak, or leave the text as-is before saving. You are always in control of the final output.

Tip

Pair bulk generation with the Global Suffix feature to automatically append consistent branding to every generated alt text site-wide.

How to use bulk generation

  • 1
    Open the Image SEO panel in RankFrame
    Navigate to the Image SEO section. Your site images are displayed in a grid, paginated as Page X of Y.
  • 2
    Click Select All
    The button is located at the top of the image grid. Every card gets a purple border and its checkbox is checked.
  • 3
    Confirm your selection
    The Generate Alt Text button appears with a live count showing how many images are selected, for example Generate Alt Text (12).
  • 4
    Click Generate Alt Text (N)
    RankFrame runs AI generation for every selected image. A progress indicator shows the job running.
  • 5
    Review and save
    Each image card now shows a filled alt text input. Edit any field you want to refine, then save your changes.

Field Reference

1
Select All / Deselect All

The master toggle at the top of the image grid. Clicking Select All instantly checks every image card visible on the current page and applies a purple border to each card. The button label changes to Deselect All so you can reverse the action with one more click. Deselecting all returns every card to its unchecked state and hides the Generate Alt Text button.

Select All / Deselect All toggle
2
Individual Image Checkboxes

Every image card has its own checkbox. Use individual checkboxes when you only want to regenerate alt text for specific images rather than the entire page. You can freely mix individual selection with the master toggle -- checking or unchecking a single card updates the Generate Alt Text counter immediately.

Individual card checkbox
3
Generate Alt Text (N) Button

A large purple button that appears at the top of the grid as soon as at least one image is selected. The number in parentheses updates live as you check or uncheck images, so you always know exactly how many images will be processed before you click. Clicking the button starts AI generation for every selected image in one batch.

Generate Alt Text (N) button
Note

The button is hidden when no images are selected. Select at least one image to make it appear.

4
Credit Cost

Bulk alt text generation costs 1 credit per image. If you select 30 images and click Generate Alt Text (30), exactly 30 credits are deducted from your account. Images that already have alt text and are not selected are never charged. Check your credit balance in the RankFrame dashboard before running large batches.

Credit balance indicator
Tip

Use individual checkboxes to skip images that already have strong, hand-written alt text and save credits for images that need AI assistance.

5
Pagination (Page X of Y)

When your site has many images, they are split across multiple pages in the grid. The current position is shown as Page X of Y with Prev and Next arrow buttons for navigation. Bulk generation applies to the images on the currently visible page. To generate alt text across all pages, navigate to each page in turn, run Select All, and click Generate Alt Text for each.

Pagination controls

Reviewing and Editing Results

After generation completes, each image card shows an input field pre-filled with the AI-written alt text. You can:

  • Leave the text as-is if it accurately describes the image
  • Click any field and type to refine the description
  • Delete the text and write your own from scratch

No changes are published until you explicitly save. Take your time reviewing before confirming.

Tip

If you want every generated alt text to end with a branded phrase such as "by Studio Name", set up the Global Suffix before running bulk generation. The suffix is appended automatically and you will not need to edit each field manually.

Frequently Asked Questions

How many credits does bulk alt text generation use?
Bulk alt text generation costs 1 credit per image. If you select 20 images and click Generate Alt Text, 20 credits are consumed. Only images that are actually generated count against your credit balance.
Can I edit the alt text after it is generated?
Yes. After generation each image card shows a filled input field with the AI-written alt text. You can click into any field and edit the text before saving. Your edits are preserved.
Does bulk generation work across all pages at once?
Bulk generation applies to the images visible on the current page of the image grid. If your site has many images spread across multiple pages (shown as Page X of Y), navigate to each page and run generation separately.
What happens if I click Select All and then deselect one image?
The master toggle switches back to Select All state and the Generate Alt Text button counter updates to reflect only the images that remain checked. You can freely mix the master toggle with individual card checkboxes.
Can I add a consistent suffix to every generated alt text?
Yes. RankFrame supports a global suffix that is automatically appended to every AI-generated alt text. See the Global Suffix article for setup instructions.
