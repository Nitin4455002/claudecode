Bulk Alt Text Generation

Generate descriptive alt text for every image on your Framer site in a single action. Select all images, let RankFrame's AI write the descriptions, then review and save.

Overview

Writing alt text for every image by hand is one of the most time-consuming tasks in web accessibility and image SEO. RankFrame's bulk generation feature solves this by letting you select every image on the current page of your image grid and run AI generation in one click.

The workflow is simple: open the Image SEO panel, select the images you want, click Generate Alt Text, and review the results. Every image gets its own editable field so you can adjust anything the AI produces before saving.

Tip

Combine bulk generation with a global suffix to automatically append your brand name or a consistent phrase to every generated alt text without any extra steps.

How to use bulk generation

  • 1
    Open the Image SEO panel in RankFrame
    Navigate to the Image SEO section from the RankFrame plugin sidebar. Your site's images appear in a grid, one card per image.
  • 2
    Click "Select All"
    The Select All button sits at the top of the image grid. Clicking it applies a purple border and a checked checkbox to every image card on the current page. The button label switches to "Deselect All" immediately so you can reverse the action if needed.
  • 3
    Confirm your selection
    A large purple Generate Alt Text (N) button appears at the top of the grid. The number N shows how many images are currently selected. You can also uncheck individual cards before proceeding to exclude specific images.
  • 4
    Click "Generate Alt Text (N)"
    RankFrame sends each selected image to the AI. Generation runs automatically and fills every alt text input field with a descriptive result. This uses 1 credit per image.
  • 5
    Review and edit the results
    Each card's input field now contains the generated alt text. Read through, make any edits you want, and save when satisfied.

Field reference

1
Select All / Deselect All

A master toggle button at the top of the image grid. Clicking Select All checks every image card on the current page and adds a purple border to each. The label changes to Deselect All, which clears all selections when clicked.

Select All button at the top of the image grid, toggling to Deselect All
2
Individual checkboxes

Every image card has its own checkbox. Use these when you want to generate alt text for specific images rather than all of them. The Generate Alt Text (N) button count updates live as you check or uncheck individual cards.

Per-card checkboxes on individual image cards in the grid
3
Generate Alt Text (N) button

A large purple button that appears at the top of the grid as soon as at least one image is selected. The number N in parentheses reflects your current selection count in real time. Clicking it triggers AI generation for all selected images simultaneously.

Purple Generate Alt Text (N) button visible above the image grid
4
Credit cost

RankFrame charges 1 credit per image generated. If you select 24 images, the operation uses 24 credits. The number inside the Generate Alt Text button shows exactly how many credits will be spent before you confirm.

Note

Credits are deducted at generation time. Deselect images you do not need alt text for before clicking Generate to avoid spending unnecessary credits.

5
Pagination

When your site has many images, the grid splits into pages shown as Page X of Y. Use the Prev and Next arrows to navigate between pages. Bulk generation applies to the images selected on the currently visible page. Navigate to the next page and repeat the selection and generation steps to cover additional pages.

Pagination controls showing "Page 1 of 3" with Prev and Next arrows

Credits and cost

Each image generated through the bulk tool consumes exactly 1 credit. The credit total is displayed inside the Generate Alt Text button before you click, giving you full visibility before committing.

To reduce credit use, deselect images that already have acceptable alt text. You can start with Select All and then uncheck individual cards to fine-tune your selection before running generation.

Working with paginated images

Large image libraries are split across multiple pages in the grid. The pagination control shows your current position as Page X of Y and provides Prev and Next arrows to move between pages.

Bulk generation is scoped to the current page selection. To process all pages:

  1. On Page 1, click Select All, then click Generate Alt Text.
  2. Click Next to move to Page 2.
  3. Repeat Select All and Generate Alt Text for each remaining page.
Tip

After generating on each page, do a quick review of the filled fields before moving on. Catching any unusual outputs page by page is faster than revisiting everything at the end.

Frequently asked questions

How many credits does bulk alt text generation use?
RankFrame uses 1 credit per image generated. The Generate Alt Text button shows the exact count before you confirm, so you always know the total cost upfront.
Can I generate alt text for only some images, not all?
Yes. Instead of using Select All, check individual image cards using the per-card checkboxes. The Generate Alt Text button updates its count to reflect only the selected images.
Does bulk generation work across all pages of images at once?
Bulk generation applies to the images selected on the currently visible page. Navigate to each page and repeat the selection and generation steps to cover additional pages.
Can I edit the generated alt text after it is created?
Yes. After generation, each image card shows the AI-written alt text in an editable input field. You can review and change any text before saving.
What happens to alt text I have already written manually?
Bulk generation only runs on the images you have selected. Images you deselect that already have manual alt text are left completely untouched.
