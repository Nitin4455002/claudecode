Export Image Data as CSV

Download a complete spreadsheet of every image on your Framer site, including filenames, URLs, alt text status, and source. Ideal for auditing, client handoffs, and bulk offline review.

RankFrame tracks the alt text status of every image across your Framer site. The CSV export turns that live data into a portable file you can open in Excel, Google Sheets, or any spreadsheet tool. One click, one file, every image.

1
Export button

The Export button is purple with a download arrow icon. It sits in the controls row at the top of the Image SEO panel, next to the search bar and filter controls. No menu navigation is required -- a single click immediately triggers a file download to your browser.

Export button in the Image SEO controls row
Tip

The button becomes active only after images have finished loading. If you see a loading indicator in the panel, wait for it to complete before clicking Export.

2
CSV contents

The downloaded file contains one row per image with four columns:

  • Filename -- the image file name as stored in Framer's asset system
  • URL / Path -- the full URL or relative path used to render the image on the page
  • Alt Text -- the current alt text value, or an empty cell if no alt text has been set yet
  • Source -- either Canvas (placed directly on the canvas) or the name of the CMS collection the image belongs to
Example CSV open in a spreadsheet application
Note

The CSV is read-only for import purposes. Editing the file and re-uploading it is not supported. To update alt text, return to the Image SEO panel inside RankFrame.

3
When to use the export

The export is most valuable in three situations:

  • Alt text audit -- Sort by the Alt Text column to instantly find which images are missing descriptions, even across a site with hundreds of images.
  • Client or team sharing -- Share the spreadsheet with a copywriter, client, or project manager who does not have access to Framer or RankFrame, so they can draft alt text and return it to you.
  • Bulk offline review -- Work through images outside the plugin environment, annotate the spreadsheet, then apply changes in batches when you return to RankFrame.
Tip

Apply a filter before exporting if you only need a subset -- for example, images from one CMS collection. The CSV will include only what is currently visible in the panel.

How to export your image data

  • 1
    Open the Image SEO panel
    Launch RankFrame inside Framer and click Image SEO in the left navigation.
  • 2
    Wait for images to load
    RankFrame scans your site automatically. A loading indicator appears while this completes. The Export button becomes active once all images are listed.
  • 3
    Apply filters (optional)
    Use the search bar or filter controls to narrow the list if you only want a subset of images in the export.
  • 4
    Click the purple Export button
    Your browser downloads a CSV file immediately. No confirmation dialog appears.
  • 5
    Open in your spreadsheet tool
    Open the file in Excel, Google Sheets, or Numbers to review, sort, and annotate your image data.

Frequently asked questions

What data is included in the exported CSV?
The CSV includes four columns for every image: filename, URL or path, current alt text (blank if missing), and the source -- either Canvas or the name of the CMS collection the image belongs to.
Does the CSV include images I have filtered out?
No. The export reflects whatever is currently loaded in the Image SEO panel. If you have applied a filter, only the filtered set appears in the CSV. Remove all filters first to export every image on the site.
Can I import an edited CSV back into RankFrame?
CSV import is not currently supported. The export is for auditing and sharing purposes. Alt text must be set inside the Image SEO panel directly.
Where is the Export button?
The Export button is purple with a download arrow icon. It sits in the controls row at the top of the Image SEO panel, next to the search bar and filter controls.
Do I need a paid plan to export?
The CSV export is available to all RankFrame users and does not consume any credits. It is a data utility, not an AI feature.
