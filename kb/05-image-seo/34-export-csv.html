Export Image Data as CSV

Download a complete spreadsheet of every image on your Framer site, including filenames, paths, alt text status, and source. Ideal for audits, client handoffs, and offline review.

The Export feature in the Image SEO panel lets you pull all image metadata out of RankFrame and into a CSV file in one click. Whether you are auditing a site with hundreds of images or handing off an alt text review to a client, the CSV gives you everything you need outside the plugin.

1
Export button
Export button in the Image SEO controls row

The Export button sits in the controls row at the top of the Image SEO panel. It is styled in purple with a download arrow icon, making it easy to spot alongside the filter and search controls. No configuration is required before clicking it.

Clicking the button triggers an immediate download. No confirmation dialog appears. The file lands in your browser's default downloads folder as a .csv file.

Tip

If you have applied a filter before clicking Export (for example, filtering to show only images with missing alt text), the downloaded CSV will reflect that filtered view. This makes it easy to share a targeted list with a copywriter or client.

2
CSV contents
Example CSV opened in a spreadsheet application

Every row in the exported file represents one image. The CSV contains four columns:

  • Filename - The image file name as stored in Framer (for example, hero-background.webp).
  • URL / Path - The full URL or relative path where the image is served.
  • Alt text - The current alt text value. This column is blank when alt text has not been added yet, making it easy to spot gaps at a glance.
  • Source - Either Canvas for images placed directly on Framer pages, or the name of the CMS collection the image belongs to (for example, Blog Posts).
Note

The CSV is a read-only export. You cannot re-import edited values back into RankFrame. Any changes to alt text must be made inside the Image SEO panel.

3
When to use export
Workflow diagram: export, review offline, update in panel

The Export feature is most useful in three scenarios:

Alt text audit

Open the CSV in a spreadsheet, sort by the alt text column, and immediately see every image that is missing a description. This works especially well on large sites where scrolling through the Image SEO grid would be slow.

Client or team handoff

Share the CSV with a client, copywriter, or content team so they can draft alt text suggestions in a familiar spreadsheet environment. Once you receive their edits, enter the values into the Image SEO panel.

Bulk offline review

Before running a batch AI generation job, export the current state as a baseline. After the job completes, export again and compare the two files to confirm every image was updated correctly.

Tip

Remove all active filters before exporting if you want a complete record of every image on the site, not just the currently visible subset.

Frequently asked questions

What columns does the exported CSV include?
The CSV includes four columns: image filename, URL or path, current alt text (blank if missing), and image source (Canvas or the name of the CMS collection the image comes from).
Does the export include every image on my site?
The export reflects whatever is currently loaded in the Image SEO panel. If you have applied a filter (for example, showing only images with missing alt text), the CSV will contain only those filtered results. Remove any filters first if you want a complete export.
Can I edit the CSV and re-import it?
Not at this time. The export is read-only and intended for auditing and sharing. Alt text must be added or edited directly inside the Image SEO panel in RankFrame.
Where does the downloaded file go?
The file downloads to your browser's default downloads folder, the same as any other file download. The filename will reference your site and the export date.
Is the Export button available on the free trial plan?
Yes. Exporting image data as CSV is available to all users regardless of plan, because it is an auditing tool that does not consume AI credits.
