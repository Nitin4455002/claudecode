How to Add Keywords to the Keyword Tracker

Adding keywords to track in RankFrame takes seconds. You can add one keyword at a time or batch-add multiple keywords in a single entry by separating them with commas. The keywords appear in the Keyword Manager table and begin accumulating Google Search Console data automatically.

Step-by-Step: Adding Keywords

Keyword Tracker tab open with the Add New Keyword input field visible at the top
  1. 1
    Open Submit Indexing and navigate to the Keyword Tracker tab.

    Click the lightning bolt icon in the left sidebar of RankFrame to open Submit Indexing. Then click the Keyword Tracker tab across the top of the panel.

  2. 2
    Click the keyword input field.

    The input field sits at the top of the tab, above the Keyword Manager table. It has a target/bullseye icon on the left and placeholder text that reads "seo on wordpress, rank math vs yoast..." to show the expected format. Click anywhere in the field to activate it.

  3. 3
    Type your keyword or keywords.

    To add a single keyword, type it and proceed. To add multiple keywords at once, separate them with commas. For example: Framer SEO plugin, best Framer plugin, Framer schema markup. No space after the comma is required.

  4. 4
    Click Save.

    Each comma-separated term becomes its own row in the Keyword Manager table immediately. The Save button sits to the right of the input field.

  5. 5
    Wait 48 to 72 hours for data to populate.

    Google Search Console data has a built-in lag. Impressions, Clicks, and Search Position cells will fill in automatically as Search Console data becomes available for your new keywords.

Comma-separated keywords typed into the Add New Keyword input field before clicking Save

Understanding Each Input Element

1 The Keyword Input Field

The input field spans the full width of the tab, above the Keyword Manager. It has a target/bullseye icon on the left (decorative, not clickable) and placeholder text suggesting example keywords in the expected format.

seo on wordpress, rank math vs yoast...

You can add multiple keywords at a time by separating them with commas.

Add New Keyword input field with bullseye icon, placeholder text, and Save button
2 Adding Multiple Keywords at Once

Separate keywords with commas. No space after the comma is required, though adding one does not cause any issue. Example entry:

Framer SEO, SEO plugin Framer, best Framer tools

After clicking Save, each term becomes an individual tracked keyword row in the table. Batch entry is the fastest way to seed your tracker on day one with all of your target terms.

Multiple comma-separated keywords entered in the input field before saving
3 What Happens After Clicking Save

Your keywords appear immediately in the Keyword Manager table. At first, the Impressions, Clicks, Search Position, and Position History cells are empty. These fill in automatically as Google Search Console data becomes available for each term.

If you added a keyword that Google has no data for yet (a very new page or a very niche term), the cells may remain empty for several days. This is normal. Data appears once Search Console has indexed impressions for that query on your site.

Keyword Manager table immediately after saving, showing new keyword rows with empty data cells
4 Keyword Manager Search

Once you have multiple keywords saved, use the search field in the Keyword Manager header to filter the table in real time. Type part of any keyword to show only matching rows. This is especially useful when your tracking list grows beyond 20 or 30 keywords and you want to jump to a specific term quickly.

Keyword Manager search field filtering the table to show only matching keyword rows

Tips for Building a Useful Tracking List

  • Track your primary target keywords from day one, before you see data, so you build baseline history from the start.
  • Include branded terms such as your studio name or product name to monitor branded search growth over time.
  • Include competitor comparison terms ("X vs Y") if your content targets that intent.
  • Keep the list under 50 keywords to keep the table readable and your reviews focused on what matters most.

Frequently Asked Questions

If you type a keyword that is already in the tracker, it is added as a duplicate row. Check the Keyword Manager before adding terms to avoid duplicates. Use the Keyword Manager search field to quickly confirm whether a term is already tracked.

Look for a delete option (trash icon or remove button) on each keyword row in the Keyword Manager. If no direct delete control is visible in your version of RankFrame, contact the support team at hello@7seersmedia.com for guidance on managing your tracked list.

There is no documented limit on batch entry. Separate as many keywords as you need with commas and click Save. All terms are added in a single action.

Delete the keyword row containing the typo and re-add the corrected version. Tracked keywords are not editable in place, so deletion and re-entry is the correct approach.

Position data comes from Google Search Console, which typically has a 48 to 72 hour lag. Keywords you add today may not display Impressions, Clicks, or Search Position data until 3 to 4 days later. This delay is a Google-side limitation, not a RankFrame issue.
