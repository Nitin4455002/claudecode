Troubleshooting

Fixing Indexing Issues

RankFrame's Submit Indexing feature uses the official Google Indexing API to push URLs directly to Google. When a submission appears to fail or nothing happens, the cause usually falls into one of five categories. This article covers each one and how to resolve it.

Five Causes of Indexing Failures

1 Trial Limit Reached
SymptomThe Push URLs button is greyed out or disabled. You cannot select any URLs to submit.
CauseTrial accounts are limited to 2 total URL submissions. Once you have submitted 2 URLs, the Push URLs feature is locked until you upgrade.
FixClick the See Billing button in the Submit Indexing panel to view upgrade options. The Personal plan and Agency plan both remove the trial submission limit and provide full daily quota access.
Submit Indexing panel showing greyed-out Push URLs button and the See Billing upgrade prompt
2 Domain Not Verified
SymptomSubmissions appear to go through but URLs do not appear in Indexing History, or the Setup tab shows an error on the Domain Verification step.
CauseRankFrame verifies your domain automatically during Google account connection. If the connected account does not have Owner or Full User access in Search Console, verification fails and submissions are rejected before they reach Google.
FixOpen Submit Indexing > Setup tab. Check the Domain Verification step for an error indicator. If verification failed, disconnect your Google account, confirm the account has Owner or Full User access in Google Search Console, then reconnect. See: Fixing Google Connection Issues.
Submit Indexing Setup tab showing Domain Verification step with error state and Disconnect button
3 Google Indexing API Quota Exceeded
SymptomSome submissions succeed but then new submissions begin returning errors, often in the middle of a batch submission.
CauseGoogle's Indexing API allows a maximum of 200 requests per day under standard access. Submitting a large sitemap at once can exhaust this quota in seconds.
FixWait 24 hours for the daily quota to reset. When you resubmit, prioritize your most important pages. Submit in small daily batches of 20 to 50 URLs rather than your entire sitemap at once.
Indexing History tab showing a mix of successful and quota-error submissions mid-batch
Quota Strategy

Google's 200-request daily quota resets at midnight Pacific Time. If you manage a large Framer site, build a habit of submitting new and updated pages only, not your full URL list, each time you publish changes.

4 URL Not in Sitemap
SymptomA URL was submitted through the Indexing API but remains unindexed after several days, even though the page is live.
CauseGoogle's Indexing API works best with URLs that are already discoverable via your sitemap. If a page was recently added and the sitemap has not been updated, Google may not be able to fully validate the URL.
FixIn the Submit Indexing panel, click Push Sitemap first to notify Google of your updated sitemap. Then resubmit the specific URL using Push URLs. Pushing the sitemap first helps Google connect the URL to your site's crawl graph.
Submit Indexing Submit URLs tab with Push Sitemap and Push URLs buttons highlighted
5 Wrong URL Format
SymptomManually entered URLs show errors or are not found, even though the page is live and accessible in a browser.
CauseThe Google Indexing API requires fully qualified absolute URLs. Relative paths such as /about are not accepted. Typos in the domain or missing https:// also cause silent failures.
FixVerify every manually entered URL starts with https:// and includes the full domain. For example, use https://yourdomain.com/about instead of /about. URLs pulled from the sitemap inside RankFrame are auto-formatted correctly.
Submit URLs input field showing the correct absolute URL format required by the Indexing API

How to Check If a URL Was Successfully Indexed

After submitting a URL, use these methods to confirm whether Google has indexed it.

Using the Check Live Button in Indexing History

Open Submit Indexing > Indexing History. Find the URL you submitted in the history list. Click the Check Live button next to that URL. RankFrame queries Google's URL Inspection API and returns the current index status directly in the panel.

The status will update to one of the following:

Status What It Means What to Do
Submitted and Indexed Google has the page in its index. No action needed.
Submitted API call was accepted. Google has not yet processed the page. Wait 24 to 72 hours, then check again.
Not Indexed Google is aware of the URL but has chosen not to index it. Review the page for noindex tags, thin content, or canonical issues using SEO Analyzer.
Error The API call failed. Common causes: quota exceeded, domain not verified, or malformed URL. Review and resolve the applicable issue from the five categories above.
Indexing History tab with Check Live button highlighted and a status result showing "Submitted and Indexed"

Using Google Search to Verify Indexing

  1. 1 Open a browser and go to google.com.
  2. 2 In the search bar, type site:yourdomain.com/your-page-slug replacing the URL with your actual page URL.
  3. 3 If Google returns a result showing that exact URL, the page is indexed. If Google returns zero results, the page is not yet in the index.
Note on Indexing Guarantees

The Google Indexing API increases the speed at which Google discovers your pages, but it does not guarantee indexing. Google still applies its own quality and relevance criteria. If a page has a noindex directive, a canonical tag pointing elsewhere, or very thin content, it may not be indexed even after a successful API submission. Use RankFrame's SEO Analyzer to check for on-page issues that could block indexing.

Frequently Asked Questions

How long does it take for Google to index a submitted URL?
After you submit a URL through RankFrame's Submit Indexing feature, Google typically processes it within a few hours to a few days. The Indexing API signals Google to crawl and index the URL, but Google makes the final decision about timing based on its own crawl scheduling and quality assessments. You can check whether a URL has been indexed using the Check Live button in the Indexing History tab, or by running a site: search in Google.
Does the Google Indexing API guarantee that my page will be indexed?
No. The Indexing API signals Google to crawl and consider the URL for indexing, but Google still applies its own quality and relevance criteria. Pages with thin content, canonical conflicts, noindex tags, or other technical SEO issues may not be indexed even after a successful API submission. Use RankFrame's SEO Analyzer to check for issues that might prevent indexing.
What does "Submitted and Indexed" mean in Indexing History?
"Submitted and Indexed" means RankFrame successfully sent the URL to the Google Indexing API and Google has confirmed the page is in its index. This is the best possible status. If you see "Submitted" without "Indexed", the API call succeeded but Google has not yet processed the page. Check back in 24 to 72 hours.
What is the daily URL submission quota for RankFrame?
RankFrame uses Google's Indexing API, which has a standard quota of 200 requests per day per project. Trial accounts are additionally limited to 2 total URL submissions. Personal and Agency plan users can submit up to 200 URLs per day before the quota resets. To stay within quota, submit new and updated pages in batches rather than your entire sitemap at once.
How should I handle indexing for a large site with hundreds of pages?
For large sites, prioritize the pages that matter most: new posts, updated landing pages, and high-value content. Submit these first using the Push URLs feature. Use Push Sitemap to ensure Google has the full URL list. Then submit remaining pages in daily batches of up to 200 to stay within Google's quota. Avoid submitting every page at once, as this exhausts your daily quota and delays the most important pages.
