Indexing History: Review and Verify Your Submitted URLs

The Indexing History tab gives you a complete log of every URL you have submitted to Google. Use it to review past submissions and confirm live indexing status without ever leaving Framer.

Overview of the Indexing History tab

The Indexing History tab is your submission audit log. Every URL you push through RankFrame's Submit URLs tab appears here, along with a timestamp, submission type, and current status. The tab also includes a header that identifies which domain the logs belong to, and a Refresh button to reload the latest entries.

The header reads: Showing logs for: [domain]. Clicking Refresh pulls the most recent submission records into the table.

Keep in mind

A green Success badge means RankFrame successfully delivered your URL to the Google Indexing API. It does not guarantee the page has been crawled and indexed yet. Use the Check Live button to query Google directly and confirm actual indexing status.

Indexing History tab showing the domain header, Refresh button, and submission log table

The info banner

At the top of the Indexing History tab, an info banner reminds you how the Check Live feature works:

"Click Check Live next to any URL to ask Google if it has successfully indexed that specific page yet. It may take hours or days for Google to crawl pushed URLs."

This reminder is important. Submission success and indexing confirmation are two separate events. The table records the first. Check Live tells you about the second.

Table columns: the five fields

The history table has five columns. Each row represents a single URL submission. Here is what each column tells you.

1
Date

The Date column shows the exact timestamp of when you submitted the URL. This is the moment RankFrame delivered the URL to the Google Indexing API, not when Google crawled or indexed the page.

Date column showing a submission timestamp in the Indexing History table

Use this column to cross-reference your submission history with any changes you made to your Framer site. If you published a page update and then submitted the URL, the timestamp confirms when that submission occurred.

2
Type

The Type column identifies the URL submission type for each entry. A globe icon appears alongside the type label, making it easy to scan the column at a glance.

Type column showing the globe icon and URL submission type label

All submissions made through the Submit URLs tab appear here with the corresponding type. This field helps you understand the context of each submission when you are reviewing a long history log.

3
URL

The URL column displays the full URL that was submitted. Long URLs are truncated in the table view to keep the layout readable, but the complete address is used when you click Check Live.

URL column showing a truncated page URL in the Indexing History table

Each row corresponds to exactly one URL. If you submitted the same URL multiple times (for example, after updating the page), each submission appears as a separate row with its own timestamp and status.

4
Status

The Status column shows whether RankFrame successfully delivered the URL to the Google Indexing API. A green Success badge means the submission was accepted without errors.

Status column showing a green Success badge in the Indexing History table

The Success badge confirms that Google received the submission request. From this point, Google decides when to crawl and index the page based on its own schedule. To find out whether Google has completed that process, use the Check Live button in the Action column.

Tip

A Success status combined with a Check Live result of "Indexed by Google" is the clearest signal that your page has been fully processed by Google.

5
Check Live

The Action column contains a Check Live button for each row. Clicking it queries Google in real time and returns the current indexing state for that specific URL. The result appears as an inline tooltip directly next to the row, showing Indexed by Google with a State of Submitted and indexed.

Check Live button in the Action column and the inline tooltip showing "Indexed by Google" with State "Submitted and indexed"

This is a live request to Google, not a cached result. The response reflects Google's actual data at the moment you click.

Timing note

If you click Check Live shortly after submitting a URL, Google may not have crawled the page yet. The tooltip will not show the "Submitted and indexed" state until Google completes its crawl. Check again after a few hours or the next day.

Using Check Live to verify indexing

The Check Live feature is what makes the Indexing History tab unique. It is the only tool in the Framer ecosystem that gives you live indexing confirmation from Google directly inside the design tool. You do not need to open Google Search Console or use an external URL inspection tool.

Here is how to use it.

  • 1
    Open the Indexing History tab
    Navigate to Submit Indexing in RankFrame and select the Indexing History tab. The table loads your submission log automatically.
  • 2
    Click Refresh if needed
    If you recently submitted new URLs and do not see them yet, click the Refresh button next to the Showing logs for: [domain] header to reload the latest entries.
  • 3
    Locate the URL you want to verify
    Find the row for the page you want to check. Use the Date and URL columns to identify the correct entry if you have submitted multiple pages.
  • 4
    Click Check Live in the Action column
    Click the Check Live button in the row for your chosen URL. RankFrame sends a live query to Google.
  • 5
    Read the inline tooltip
    A tooltip appears inline next to the row. If Google has indexed the page, it displays Indexed by Google with a State of Submitted and indexed. If the page has not been indexed yet, the tooltip will reflect that current state instead.

What to do after checking live status

The result from Check Live tells you where each page stands in Google's indexing pipeline. Here are the most common outcomes and what to do with each.

Indexed by Google (State: Submitted and indexed)

Your page is in Google's index. No further action is needed for this URL. You can move on to verifying other pages or reviewing your ranking data in the Analytics tab.

Not yet indexed

Google received your submission but has not completed the crawl yet. This is normal, especially for newly published pages. Wait several hours or check back the following day. If the page has been live for more than a few days and still shows no indexing confirmation, consider re-submitting the URL from the Submit URLs tab.

Tip

You can re-submit any URL at any time from the Submit URLs tab. Re-submitting a URL that is not indexed yet sends a fresh signal to Google and may help prompt an earlier crawl.

Frequently asked questions

What does the Check Live button actually do?
Check Live sends a real-time query to Google and returns the current indexing state for that specific URL. If Google has indexed the page, the inline tooltip displays Indexed by Google with a State of Submitted and indexed. The result reflects Google's live data at the moment you click, not a cached snapshot.
How long does it take for a submitted URL to appear as indexed?
Indexing timelines vary. Google typically crawls and indexes submitted pages within hours to a few days. A green Success badge in the Status column means RankFrame successfully delivered the URL to the Google Indexing API. It does not mean the page is already indexed. Use Check Live to confirm actual indexing status.
Why does my URL show a Success badge but Check Live does not confirm indexing yet?
The Success badge confirms that RankFrame successfully submitted your URL to the Google Indexing API. Google acknowledged the request. However, Google still needs time to crawl and process the page. Check Live may not return "Indexed by Google" until Google has completed that crawl, which can take hours or days.
Can I check multiple URLs at once with Check Live?
No. Check Live is a per-URL action. Click the Check Live button in the Action column for each URL you want to verify. The tooltip result appears inline next to the row you selected.
Is RankFrame the only tool that shows live Google indexing confirmation inside Framer?
Yes. RankFrame is the only tool in the Framer ecosystem that queries Google for live indexing confirmation and displays the result directly inside the design tool. You do not need to leave Framer or log into Google Search Console to verify whether a specific page has been indexed.
