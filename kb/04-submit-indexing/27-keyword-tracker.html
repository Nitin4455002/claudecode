Keyword Tracker

The Keyword Tracker tab in RankFrame lets you manually add the search terms you care about, then shows impressions, clicks, average position, and a position history sparkline for each one. All data is sourced from Google Search Console through your connected account.

Overview

The Keyword Tracker tab is split into two areas. At the top, the Add New Keyword input lets you manually enter the keywords you want to monitor. Below that, the Keyword Manager table lists every saved keyword alongside its performance metrics.

Keywords do not sync automatically from Google Search Console. You decide which terms to track by copying them from GSC and pasting them here. This keeps your tracker focused on the keywords that matter most to your project.

Important

There is no automatic keyword import or discovery. Keywords must be added manually. Go to Google Search Console, find the queries driving traffic to your site, then paste them into the Add New Keyword field.

How to add keywords

  • 1
    Open Google Search Console
    Go to search.google.com/search-console and select your Framer site. Navigate to the Search results report and review the top queries.
  • 2
    Copy the keywords you want to track
    Select one or more query strings from the GSC table and copy them. You can combine multiple keywords by separating them with commas before pasting.
  • 3
    Paste into the Add New Keyword field
    Open RankFrame, go to the Keyword Tracker tab, and paste your keywords into the Add New Keyword input. Separate multiple entries with commas.
  • 4
    Click Save
    Press the Save button next to the input. RankFrame adds each keyword as a new row in the Keyword Manager table and begins populating its metrics.

Field reference

1
Add New Keyword

The text input at the top of the Keyword Tracker tab. It is marked with a target (bullseye) icon. Placeholder text reads: seo on wordpress, rank math vs yoast...

Type or paste your target keywords into this field. Keywords must be added manually. The recommended workflow is to open Google Search Console, copy the query strings you want to monitor, then paste them here. RankFrame does not automatically sync or discover keywords from GSC or any other source.

To add multiple keywords in one go, separate each term with a comma. For example: framer seo plugin, framer vs webflow seo, framer sitemap. RankFrame will create one row per keyword when you save.

After entering your keywords, click the Save button to the right of the input. Each keyword is added to the Keyword Manager table immediately.

Tip

The helper text below the input reads: "You can add multiple keywords at a time by separating them with commas." Use this to bulk-import a list from GSC in one paste.

2
Keyword Manager search

A search field inside the Keyword Manager section. Use it to filter the keyword table by typing part of a keyword.

As your tracked keyword list grows, the search field helps you quickly locate a specific term without scrolling through the entire table. Type any substring of a keyword and the table filters in real time to show only matching rows.

Keyword Manager section with search field and table
3
KEYWORD column

Displays the exact keyword string you saved. Each row in the Keyword Manager table represents one keyword.

The text shown here is exactly what you typed or pasted into the Add New Keyword input. Keywords are case-insensitive in search engines, but RankFrame preserves the original casing you entered for display purposes.

4
IMPRESSIONS column

Shows the total number of times this keyword caused any page on your site to appear in Google search results during the tracked period.

Impressions count every time a user saw your site in a search results page for this keyword, even if they did not click. This number comes from Google Search Console through your connected Google account. A high impression count with low clicks suggests your title or meta description may need improvement to attract more clicks.

5
CLICKS column

Shows the total number of times users clicked a result from your site after searching for this keyword.

Clicks represent actual visits driven by organic search for this keyword. Compare this column against IMPRESSIONS to calculate your click-through rate (CTR). If impressions are high but clicks are low, consider testing a stronger page title or a more compelling meta description for the pages ranking for this term.

6
SEARCH POSITION column

Displays the current average ranking position for this keyword across all pages on your site.

Position 1 is the top result. Lower numbers are better. Google Search Console calculates this as an average across all impressions for the keyword during the period, so fractional positions like 2.4 are normal.

When your ranking improves compared to the previous period, RankFrame shows a green up arrow next to the position number along with a delta value. For example:

2.4 ▲ +0.3

This means your average position is currently 2.4 and improved by 0.3 positions since the last recorded period.

7
POSITION HISTORY column

Displays a sparkline mini chart that visualizes how your average search position for this keyword has changed over time.

Each data point on the sparkline represents the average position recorded during a previous period. Because lower position numbers mean higher rankings, a line that trends downward on the chart indicates improving rankings. A line that trends upward indicates declining rankings.

Use the sparkline to spot trends at a glance. A keyword showing a steady downward trend is responding well to your SEO work. A keyword trending upward may need attention, such as a content update or additional internal links.

Tip

Sparklines are most useful after a keyword has been tracked for several periods. Freshly added keywords will show limited history until enough data has accumulated.

Frequently asked questions

Does RankFrame automatically pull keywords from Google Search Console?
No. Keywords must be added manually. Open Google Search Console, find the queries that matter to your site, then copy and paste them into the Add New Keyword field in RankFrame. There is no automatic keyword syncing or discovery.
Can I add more than one keyword at a time?
Yes. Type or paste multiple keywords separated by commas in the Add New Keyword input field, then click Save. RankFrame will create a separate row for each keyword you entered.
Where do the impressions and clicks numbers come from?
The Impressions and Clicks columns pull data from Google Search Console via RankFrame's connected Google account. Impressions shows how many times the keyword appeared in Google search results. Clicks shows how many times users clicked through to your site for that keyword.
What does the Position History sparkline show?
The sparkline is a mini chart that plots your average search position for that keyword over time. A line trending downward (toward position 1) means your ranking is improving. Each data point represents a recorded average position from a previous period.
What does the green up arrow next to the position number mean?
A green up arrow with a delta value (for example, +0.3) indicates your ranking improved since the last recorded period. For example, a Search Position of 2.4 with a +0.3 indicator means your average position moved up 0.3 places toward position 1.
