What is schema markup

Schema markup is structured data you add to a webpage to help search engines understand its content. It uses a vocabulary defined at Schema.org, agreed on by Google, Bing, and other major search engines.

Without schema markup, Google reads your page text and guesses what the page is about. With schema markup, you tell Google explicitly: this is an article written by this organization, published on this date, targeting this topic. Google uses that information to build richer search results and route queries more accurately.

Schema markup does not change anything visible on your page. It lives in the <head> as a JSON script tag and is read only by search engine crawlers.

What rich results schema unlocks

When Google validates your schema, it can display your page with enhanced features in search results. These are called rich results. They make your listing larger, more informative, and visually distinct from plain blue links.

  • B
    Breadcrumb trail Shows your site hierarchy below the page title instead of a raw URL. Improves click-through rate and makes your brand feel more authoritative.
  • F
    FAQ dropdowns Expands question-and-answer pairs directly in the search result. Your listing takes up significantly more vertical space on the results page.
  • A
    Article date and author Surfaces the publish date, author name, and publisher for news and article pages. Signals freshness and credibility.
  • K
    Knowledge panel entries Organization schema can feed Google's knowledge panel for your brand. Helps branded searches show a rich right-side card with your logo, links, and description.
Tip

Rich results are not guaranteed just because schema is present. Google decides whether to display them based on content quality, schema accuracy, and query relevance. But without schema, you have no chance of qualifying for them at all.

Why RankFrame uses JSON-LD

There are three ways to add schema to a page: JSON-LD, Microdata, and RDFa. Google recommends JSON-LD because it lives in one clean script block in the page head, separate from your HTML content.

Microdata and RDFa require you to annotate individual HTML elements with schema attributes. This couples your schema to your markup and makes it fragile: changing a heading or a paragraph can break your structured data silently.

JSON-LD has no such dependency. RankFrame injects a single <script type="application/ld+json"> block per page. If you redesign your Framer site completely, your schema is unaffected.

Note

RankFrame uses a deduplication check on every publish. If a page already has a schema block from a previous RankFrame injection, the old one is replaced cleanly. You will never end up with duplicate script tags stacking up in your page head.

Schema types in RankFrame

RankFrame supports eight schema types. Each targets a different kind of page or site. You can set one default type at the global level and override it on any individual page.

Most common

Best for company homepages, about pages, and brand landing pages. Establishes your business identity in Google's knowledge graph.
Blog and news

Events

Best for conference pages, webinar landing pages, and event registrations. Surfaces event date, location, and registration link in search.

How RankFrame injects schema

RankFrame reads your Framer sitemap to discover every page on your site. When you generate schema, RankFrame creates the correct JSON-LD block for each page based on the schema type you select and the context you have added in your Personalization settings.

The injection process works in three stages:

  1. Generation: RankFrame builds the JSON-LD object for each page using your brand context, page title, and page URL.
  2. Review: You see a preview of each schema block before it goes live. You can edit any field or regenerate using AI.
  3. Injection: RankFrame pushes the confirmed schema to each page head via the Framer API. It replaces any previously injected schema block to prevent duplication.

Once injected, schema persists across Framer publishes. You only need to regenerate if you change your site structure, add new pages, or want to update the schema content.

Tip

Fill out your Personalization settings before generating schema. The more context RankFrame has about your brand, the more accurate and keyword-rich the generated schema will be.

Frequently asked questions

Does schema markup directly improve my search rankings?
Schema markup does not directly change your position in search results. It helps Google understand your content better and can unlock rich results features like FAQ dropdowns, breadcrumb trails, and knowledge panel entries. These richer appearances increase click-through rates, which over time signals relevance to Google.
Do I need to add schema markup manually to every page?
No. RankFrame generates and injects schema automatically for every page in your Framer sitemap. You can set a global schema type for the whole site and override it on specific pages.
What schema types does RankFrame support?
RankFrame supports Organization, Article, BlogPosting, Service, Person, Product, LocalBusiness, FAQPage, and Event schema types. You can apply one type globally and override it per page.
Will schema markup affect how my Framer site looks?
No. JSON-LD schema is injected into the page head as a script tag. It is invisible to visitors and has no effect on your site's visual design or layout.
How does Google use JSON-LD schema?
Google reads JSON-LD to extract structured facts about your page: who created it, what it is about, how it is organized, and whether it qualifies for enhanced search features. It uses this to build knowledge graphs, display rich snippets, and route queries to the most relevant results.
