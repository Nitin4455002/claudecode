What book schema does

Book schema tells Google that a page is about a specific book. When the schema is valid and includes review data, Google may display review stars in search results. When edition data is included, Google can surface links to specific formats (Hardcover, Paperback, Ebook) directly in search.

This schema type is useful for author sites, book landing pages, and reading list pages built on Framer.

Book Title, URL, Author

Basic Fields
Field What to enter
Book Title The full title of the book exactly as it appears on the cover (e.g. "The Design of Everyday Things"). Becomes the name property in the JSON-LD output.
URL The canonical URL of the page about this book (e.g. https://yourdomain.com/books/my-book). Becomes the url property.
Author The full name of the book's author (e.g. "Don Norman"). If there are multiple authors, enter the primary author. Becomes author.name.

Review Details

Review Details

The Review Details section adds a structured review to the book schema. This data enables review stars in Google Search results when the schema is valid.

Field What to enter
Reviewer Name The name of the person or organization writing the review (e.g. "Jane Smith" or "Acme Book Reviews"). Becomes review.author.name.
Rating Value The numeric score given to the book (e.g. 4.5). Must be a number between 1 and the Best Rating value. Becomes review.reviewRating.ratingValue.
Best Rating The maximum possible score on the rating scale (e.g. 5 for a 5-star scale, or 10 for a 10-point scale). Becomes review.reviewRating.bestRating.
Note

For review stars to appear in Google Search, the rating must follow Google's structured data review guidelines. The reviewer should be the website owner or a real person publishing the review on that page, not an aggregated third-party rating.

Editions

Editions

The Editions section is a repeater. Each row represents one edition or format of the book. Click Add Edition to add a new row. You can add as many editions as apply.

Each edition row contains four fields:

Field What to enter
Format The physical or digital format of this edition (e.g. Hardcover, Paperback, Ebook, Audiobook). Becomes workExample.bookFormat.
ISBN The International Standard Book Number for this specific edition (e.g. 978-0-465-06710-7). Each format typically has a different ISBN. Becomes workExample.isbn.
URL A direct URL to a purchase page, listing page, or download page for this specific edition format. Becomes workExample.url.
Date The publication date for this edition in ISO 8601 format: YYYY-MM-DD (e.g. 2024-03-15). Becomes workExample.datePublished.
Tip

Add one edition row per format. If a book has Hardcover, Paperback, and Ebook editions, add three rows, one for each.

Saving and injecting

  1. Click the Preview JSON tab to review the complete JSON-LD output including all editions.
  2. Click Validator (Ext) to check the schema against Google Rich Results Test.
  3. Click Copy JSON if you want a copy of the raw JSON-LD.
  4. Click Save Schema to save it to Saved Schemas.
  5. Toggle the schema on, then click Save and Inject.

Frequently asked questions

What is Book schema used for?
It marks up a page about a book so Google understands the title, author, review score, and available edition formats. Valid book schema with review data can trigger review stars in Google Search results.
How do I add multiple editions?
Click Add Edition in the Editions section to add a new row. Each row has Format, ISBN, URL, and Date fields. Add one row per edition format.
What should I enter for Best Rating?
Best Rating is the maximum score on your scale. If you use 5-star ratings, enter 5. The Rating Value is the actual score given, which must be less than or equal to Best Rating.
What format options are available for editions?
Common formats include Hardcover, Paperback, Ebook, and Audiobook. Enter the format name as it should appear for that edition.
