What book schema does

Book schema tells Google that a page is about a specific book. When the schema is valid and includes review data, Google may display review stars in search results. When edition data is included, Google can surface links to specific formats (Hardcover, Paperback, Ebook) directly in search.

This schema type is useful for author sites, book landing pages, and reading list pages built on Framer.

Book Schema Setup & Available Options

Now let's have a closer look at each of the available options in detail.

Basic Info

1
Book Title

Enter the full title of the book exactly as it appears on the cover and title page (for example, "The Design of Everyday Things"). Do not abbreviate or alter the title. Google uses this to match the schema against its knowledge graph of books. This value populates the name property in the JSON-LD output.

2
URL

Enter the canonical URL of the page about this book (for example, https://yourdomain.com/books/my-book). This should be the permanent, preferred address for this page. This value populates the url property in the JSON-LD output.

3
Author

Enter the full name of the book's primary author (for example, "Don Norman"). If there are multiple authors, enter the primary author here. Use the name exactly as it appears in official publications and author profiles so Google can match the entity. This value populates the author.name property.

Review Details

The Review Details section adds a structured review to the book schema. Valid review data with a rating can trigger review stars in Google Search results.

4
Reviewer Name

Enter the name of the person or organization writing the review (for example, "Jane Smith" or "Acme Book Reviews"). The reviewer should be the website owner or a real person publishing an original review on this page, not a third-party aggregated rating. This value populates the review.author.name property.

5
Rating Value

Enter the numeric score given to the book in this review (for example, 4.5 on a 5-point scale). The value must be greater than or equal to 1 and less than or equal to the Best Rating value. Use the actual score you would give this book, not an averaged third-party score. This value populates the review.reviewRating.ratingValue property.

6
Best Rating

Enter the maximum possible score on your rating scale. If you rate books out of 5 stars, enter 5. If you rate out of 10, enter 10. This value must be greater than or equal to the Rating Value. It tells Google the ceiling of your scale so the rating can be interpreted correctly. This value populates the review.reviewRating.bestRating property.

Editions

The Editions section is a repeater. Click Add Edition to add a new row for each format of the book. Each row represents one edition and has four fields. Add as many rows as you have edition formats (Hardcover, Paperback, Ebook, Audiobook, etc.).

7
Format

Enter the physical or digital format of this edition (for example, Hardcover, Paperback, Ebook, or Audiobook). Use a clear, consistent label for each format so readers and Google understand the difference between editions. This value populates the workExample.bookFormat property for this edition row.

8
ISBN

Enter the International Standard Book Number for this specific edition (for example, 978-0-465-06710-7). Each format typically has a different ISBN. Use the ISBN-13 format when available. This value populates the workExample.isbn property and allows Google to uniquely identify this edition in its book database.

9
URL

Enter a direct URL to a purchase page, listing page, or download page for this specific edition format (for example, an Amazon product page or a direct download link for the Ebook). This helps readers go directly to the format they want. This value populates the workExample.url property for this edition row.

10
Date

Enter the publication date for this specific edition in ISO 8601 format: YYYY-MM-DD (for example, 2024-03-15). Different editions are often published on different dates. Use the date this format was first made available to readers. This value populates the workExample.datePublished property for this edition row.

Tip

Add one edition row per format. A book with Hardcover, Paperback, and Ebook editions needs three rows, one for each. Each row can have a different ISBN, URL, and publication date.

Saving and injecting

  1. Click the Preview JSON tab to review the complete JSON-LD output including all editions.
  2. Click Validator (Ext) to check the schema against Google Rich Results Test.
  3. Click Copy JSON if you want a copy of the raw JSON-LD.
  4. Click Save Schema to save it to Saved Schemas.
  5. Toggle the schema on, then click Save and Inject.

Frequently asked questions

What is Book schema used for?
It marks up a page about a book so Google understands the title, author, review score, and available edition formats. Valid book schema with review data can trigger review stars in Google Search results.
How do I add multiple editions?
Click Add Edition in the Editions section to add a new row. Each row has Format, ISBN, URL, and Date fields. Add one row per edition format.
What should I enter for Best Rating?
Best Rating is the maximum score on your scale. If you use 5-star ratings, enter 5. The Rating Value is the actual score given, which must be less than or equal to Best Rating.
What format options are available for editions?
Common formats include Hardcover, Paperback, Ebook, and Audiobook. Enter the format name as it should appear for that edition.
