How to Edit and Customize Schema Fields

AI generation gives you a strong starting draft. This guide covers how to refine individual fields, add custom properties, switch schema types, and edit raw JSON for full control.

Opening the schema editor

Every page in RankFrame has its own schema editor. To open it:

  1. Open RankFrame in Framer and go to Global SEO Settings.
  2. Select the Schema tab.
  3. Click any page in the list. The schema editor opens below the page row.

If the page has existing schema (generated by AI or previously saved manually), the editor shows the current fields. If the page has no schema yet, the editor shows an empty form with the global default type pre-selected.

Editing individual fields

The schema editor displays each property as a labeled text field. Click any field and type to edit it. Fields accept plain text. For properties that expect a URL (such as url, logo, or sameAs), type the full URL including the protocol.

Common fields across all types

Field What to enter Status
name The name of the entity (business name, article title, product name) Required
url The canonical URL of the page Required
description A concise summary of the entity in 1 to 3 sentences Optional
image Full URL of a representative image (logo, OG image, or product photo) Optional
sameAs Comma-separated list of social profile URLs that represent the same entity Optional
Tip

Write the description field with your target keyword in the first sentence. Schema descriptions are read by Google's language models and can influence how the page is understood topically, even though they are not visible to users.

Required vs optional fields

RankFrame marks required fields with a red label in the editor. These fields must have a value before you can save the schema. Missing required fields will trigger a validation warning and may prevent Google's Rich Results Test from validating the schema.

Optional fields add depth and specificity. They will not cause errors if left blank, but filling them in improves schema accuracy. For example, adding foundingDate to Organization schema, or datePublished to Article schema, feeds Google additional signals about your content.

Note

Google's Rich Results Test may show warnings for missing optional fields. Warnings do not prevent the schema from being used, but fixing them improves eligibility for enhanced search appearances.

Changing the schema type for a page

To change the schema type on a specific page without regenerating all fields:

  1. Open the schema editor for the page.
  2. Click the Type dropdown at the top of the editor.
  3. Select the new schema type.

RankFrame updates the field list to match the new type. Fields shared between the old and new types (such as name, url, and description) retain their values. Fields specific to the old type are removed. New type-specific fields appear empty for you to fill in.

Warning

Type-specific fields from the previous type are deleted when you switch types. If you have content in those fields you want to keep, copy it before switching.

Raw JSON editor mode

Advanced users can switch from the form-based editor to a raw JSON editor. Click Edit raw JSON at the top right of the schema editor to open the raw mode.

In raw mode you can:

  • Add nested objects and arrays that the form editor does not expose
  • Use schema properties not listed in RankFrame's default field set
  • Paste a custom JSON-LD block you have written or validated externally

RankFrame validates the JSON structure when you click Save in raw mode. Syntax errors are highlighted inline. The schema will not save until all errors are resolved.

Tip

Use the raw editor to add sameAs arrays with multiple social profile URLs, or to nest contactPoint objects inside Organization schema. These are fully supported by Schema.org and Google but are not exposed as simple fields in the form editor.

Saving and injecting

Click Save after editing to commit your changes to RankFrame. Saving does not immediately update your live site. The updated schema is injected into the page head the next time you publish the site in Framer.

To see the injected schema on your live site, publish your Framer site after saving, then inspect the page source or use Google's Rich Results Test to confirm the schema is present and valid.

Frequently asked questions

Can I write raw JSON-LD instead of using the field editor?
Yes. RankFrame includes a raw JSON editor mode for advanced users. Switch to raw mode in the Schema tab to edit the JSON-LD directly. The editor validates your JSON structure before saving and highlights any errors.
Will manual edits be overwritten if I regenerate with AI?
Yes. Clicking Generate with AI replaces the current schema with a new AI draft. If you have made manual edits you want to keep, do not regenerate. Instead, edit the existing fields directly and save.
Can I change the schema type for a page without regenerating all fields?
Yes. Change the type in the Type dropdown for the page. RankFrame will update the schema structure to match the new type. Fields that are shared between types carry over. Type-specific fields that do not apply to the new type are removed.
What fields are required versus optional?
Required fields are marked in the schema editor. For most types, name and url are always required. Google may not validate your schema for rich results if required fields are missing. Optional fields add depth but will not cause validation errors if absent.
