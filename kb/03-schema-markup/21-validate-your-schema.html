How to Test and Validate Your Schema

After RankFrame injects schema, use Google's Rich Results Test and Search Console to confirm your structured data is valid, error-free, and eligible for rich results in search.

Validation tools

Three tools cover the full validation workflow for schema markup on your Framer site.

Google Rich Results Test
Start here
Google's official tool for testing structured data. Enter a live URL or paste raw HTML. It shows detected schema types, which ones qualify for rich results, and a list of errors and warnings per type.
Use this first after every schema change to confirm Google can read and validate your schema.
Schema.org Validator
Deep validation
The official Schema.org validation tool checks your JSON-LD against the complete Schema.org vocabulary, including properties and types that Google does not surface in the Rich Results Test. More thorough but less Google-specific.
Use this when you want to verify custom or extended schema properties beyond what Rich Results Test covers.
Google Search Console
Ongoing monitoring
Search Console's Enhancements report tracks rich result eligibility across your entire site over time. It surfaces schema issues that appear after Google's crawler processes your pages, which can differ from pre-publish validation results.
Check weekly for new errors or warnings across all pages. Use it alongside the Rich Results Test, not instead of it.

Using Google Rich Results Test

  1. 1
    Publish your Framer site
    RankFrame injects schema on publish. The live URL must be accessible for the Rich Results Test to crawl it. If you have not published yet, paste your page HTML into the code snippet input instead.
  2. 2
    Open the Rich Results Test
    Go to search.google.com/test/rich-results and paste your page URL into the URL field. Click Test URL.
  3. 3
    Review the detected items
    The results panel shows each detected schema type: Article, Organization, BreadcrumbList, FAQPage, and so on. A green checkmark means it qualifies for rich results. A warning icon means issues were found. A red X means the type has blocking errors.
  4. 4
    Expand each type to see field-level detail
    Click any schema type in the results to see a field-by-field breakdown. Errors and warnings are listed with the property name and a description of the issue.
  5. 5
    Fix errors in RankFrame and republish
    Return to RankFrame, open the schema editor for the page, correct the flagged fields, save, and publish in Framer. Re-run the test after publishing to confirm the errors are resolved.
Tip

Run the Rich Results Test on your most important pages first: homepage, key service or product pages, and any high-traffic blog posts. Fix errors on those before moving to lower-priority pages.

Monitoring in Google Search Console

Google Search Console provides site-wide schema monitoring under the Enhancements section of the left sidebar. Each detected schema type gets its own report showing valid items, warnings, and errors across all your pages.

Search Console reports can lag by several days after a publish. They reflect what Google has actually crawled and processed, which makes them more authoritative than pre-publish validation but slower to update.

When Search Console shows a new error for a schema type:

  1. Click the error to see which pages are affected.
  2. Open one of those pages in the Rich Results Test to get field-level detail.
  3. Fix the issue in RankFrame, save, and publish.
  4. Return to Search Console and click Validate fix to ask Google to re-crawl the affected pages.

Common errors and how to fix them

Error Type Fix in RankFrame
Missing field: name Error Open the schema editor for the page and fill in the name field with the entity name.
Missing field: author Error For Article and BlogPosting schema, add an author object with at minimum a name property.
Invalid URL format Error Check any URL field (url, logo, image, sameAs) and ensure it begins with https:// and is a complete, valid URL.
Missing recommended field: image Warning Add a full URL to a relevant image. For Organization schema, use your logo URL. For Article, use the post's hero image URL.
Missing recommended field: datePublished Warning For Article and BlogPosting schema, add a datePublished value in ISO 8601 format (YYYY-MM-DD).
FAQPage: no questions detected Error FAQPage schema requires at least one Question entity. Ensure your schema includes a mainEntity array with at least one Question and acceptedAnswer pair.

After fixing errors

After correcting schema errors in RankFrame and publishing your Framer site, re-run the Rich Results Test on the affected page to confirm the errors are cleared. Valid schema returns a green checkmark for the relevant type.

Rich results in Google search results do not appear immediately after validation passes. Google crawls on its own schedule. For faster re-indexing, use the URL Inspection tool in Google Search Console to request indexing for the updated page.

Note

Even after validation passes and Google re-crawls, rich result display is not guaranteed. Google makes the final decision on whether to show rich results for each page based on content quality and query context. Valid schema is required but not sufficient.

Frequently asked questions

My schema passes validation but I still do not see rich results. Why?
Passing validation confirms your schema is technically correct, but Google decides independently whether to display rich results for a page. Factors include content quality, page authority, crawl frequency, and query relevance. New pages may take days or weeks before rich results appear, even with valid schema.
How long does it take for Google to pick up new schema?
Google re-crawls pages on its own schedule, which can range from hours to several weeks depending on your site's crawl budget and domain authority. Use the URL Inspection tool in Google Search Console to request a re-index after publishing schema changes.
What is the difference between an error and a warning in the Rich Results Test?
An error means a required field is missing or invalid. The schema type will not qualify for rich results until the error is fixed. A warning means an optional or recommended field is absent. Warnings do not prevent rich results but improving them can increase the richness of the display.
Can I test schema before publishing my Framer site?
Yes. The Rich Results Test accepts raw HTML in addition to live URLs. Copy your page source after RankFrame generates the schema and paste it into the code snippet input on the Rich Results Test page. This lets you validate schema before it goes live.
