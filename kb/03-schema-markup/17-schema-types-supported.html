Choosing the right type

Each schema type signals a specific kind of content to Google. Choosing the wrong type will not break your site, but it reduces the accuracy of your structured data and may prevent you from qualifying for relevant rich results.

Use the rule of thumb: pick the type that most accurately describes the primary purpose of the page, not the site. A homepage is about your organization. A blog post is about an article. A services page is about a service. Your schema type should follow that distinction.

Tip

Set Organization as your global default, then override individual pages where a more specific type applies. Most Framer sites have one organization and several different page types.

Organization

Organization
Most common
Identifies the business or entity behind the site. Feeds Google's knowledge graph with your brand name, logo, URL, contact details, and social profiles. The foundation of most business websites.
Key fields
name url logo description sameAs (social profiles) contactPoint foundingDate
Best for Homepages, about pages, company landing pages, brand sites

Article and BlogPosting

Article / BlogPosting
Written content
Marks a page as editorial content. Surfaces the headline, author, publisher, publication date, and modified date in search results. BlogPosting is a subtype of Article suited for informal or diary-style posts.
Key fields
headline author publisher datePublished dateModified description image
Best for Blog posts, case studies, announcements, editorial pages, CMS collection items

Service

Service
Services
Describes a specific service offered by the organization. Tells Google what the service does, who provides it, and who it is for. Useful for agency service pages and SaaS feature pages where each page describes one offering.
Key fields
name description provider serviceType areaServed url
Best for Agency service pages, SaaS feature pages, consulting offering pages

Person

Person
Personal brand
Identifies an individual rather than a company. Includes name, job title, employer, biography, and links to social profiles. Helps Google associate your name with your expertise and online presence across multiple platforms.
Key fields
name jobTitle worksFor description url sameAs (social profiles) image
Best for Portfolio sites, personal brand sites, freelancer pages, creator homepages

Product

Product
Product pages
Describes a specific product including name, image, description, brand, and optionally price and availability. Can unlock product rich results in Google Shopping and standard search, including price display and availability status.
Key fields
name description image brand offers (price) availability sku
Best for Product landing pages, digital product pages, Framer sites selling a specific item or template

LocalBusiness

LocalBusiness
Local search
Extends Organization with physical location details. Feeds Google Maps, local pack results, and the business hours display in Knowledge Panels. Requires a valid street address. Not recommended for fully remote or online-only businesses.
Key fields
name address telephone openingHours geo (lat/lon) priceRange url
Best for Restaurants, studios, clinics, retail shops, any business with a physical address

FAQPage

FAQPage
Help content
Marks a page that contains a list of questions and answers. Unlocks FAQ rich result dropdowns directly in Google search results. Each Q&A pair is indexed individually, which can capture additional long-tail query traffic.
Key fields
mainEntity (array of Q&A) Question: name Answer: text
Best for FAQ pages, help center articles, pricing pages with FAQ sections, any page with Q&A content
Note

FAQPage schema can be combined with another primary type. A Service page can have Service schema as its primary type and FAQPage schema added alongside it if the page contains a FAQ section.

Event

Event
Events
Describes a scheduled event including name, date, location, organizer, and registration URL. Can appear in Google's event rich results with date and ticket information displayed directly in the search snippet.
Key fields
name startDate endDate location organizer eventStatus offers (tickets)
Best for Conference pages, webinar landing pages, workshop registrations, product launches

Frequently asked questions

Which schema type should I use for a SaaS landing page?
Use Organization schema for your homepage to establish brand identity, and Service schema for individual feature or use-case pages. This combination covers brand signals and specific service descriptions.
Can I use multiple schema types on one page?
Yes. RankFrame allows you to apply a primary schema type per page. FAQPage schema can be added alongside any primary type. For example, a Service page can have both Service schema and FAQPage schema simultaneously.
Does schema type affect my global settings or just specific pages?
You set one default schema type in Global SEO Settings that applies to all pages. You can then override this on any individual page using the per-page schema settings. Pages without an override inherit the global type.
What is the difference between Article and BlogPosting schema?
Article is a broader type for any editorial content. BlogPosting is a subtype of Article specifically for informal blog entries. Both work well for written content. Use Article for formal or journalistic content, BlogPosting for conversational posts.
Is LocalBusiness schema useful for online-only businesses?
LocalBusiness schema is primarily designed for businesses with a physical address. If your business is fully online, Organization schema is the better choice. Using LocalBusiness without a valid address can trigger validation warnings.
