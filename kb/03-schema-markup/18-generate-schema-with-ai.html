Before you start

AI schema generation pulls from two sources: your Personalization settings and your Framer sitemap. The richer your Personalization data, the more accurate and complete the generated schema will be.

Required
Site connected
Your Framer site must be connected in RankFrame so the plugin can read your page list.
Required
AI credits available
Each page generation uses 1 credit. Check your credit balance in the dashboard before starting a bulk run.
Recommended
Personalization filled in
Business name, description, logo, contact, and social links give the AI more to work with. Sparse settings produce sparse schema.
Recommended
Schema type selected
Decide on a global schema type before generating. You can override per page, but having a default saves time.

Steps to generate schema

  1. 1
    Open RankFrame and go to Global SEO Settings
    In Framer, open the plugin panel and select Global SEO Settings from the left navigation.
  2. 2
    Select the Schema tab
    Click the Schema tab at the top of the Global SEO Settings panel. You will see your page list and the current schema status for each page.
  3. 3
    Choose a schema type
    Select a schema type from the Type dropdown. This applies as the default for all pages. You can override this per page after generation.
  4. 4
    Select a page and click Generate with AI
    Click any page in the list to expand it, then click Generate with AI. RankFrame reads your Personalization settings and the page URL to write the schema fields. Generation takes 5 to 10 seconds per page.
  5. 5
    Review the generated fields
    The AI output appears in an editable form. Check each field: name, description, URL, and type-specific fields like author or serviceType. Edit anything that needs adjustment before saving.
  6. 6
    Click Save
    Click Save to confirm the schema. RankFrame stores it and injects the JSON-LD block into the page head the next time you publish in Framer. The page status changes to Schema ready.
Tip

You do not need to republish your Framer site after every schema edit. RankFrame batches schema injection for the next time you publish, so you can generate and refine schema for multiple pages before triggering a single publish.

Bulk generation for all pages

To generate schema for every page at once, click Select all in the page list, then click Generate with AI. RankFrame processes each page in sequence using your global schema type as the default.

Bulk generation uses one credit per page. A site with 20 pages will use 20 credits. After bulk generation completes, review each page individually to adjust type overrides or edit any fields that need refinement.

Note

Bulk generation applies the global schema type to all pages. Pages that need a different type, for example blog posts that should use Article instead of your global Organization type, will need to be updated individually after the bulk run.

Schema for CMS collection pages

RankFrame detects CMS collection items from your Framer sitemap and lists them alongside static pages in the Schema tab. AI generation works the same way: select a collection item, choose a schema type, and click Generate with AI.

For most blog collection items, Article or BlogPosting schema is the best fit. RankFrame can map CMS fields like title, author, and publish date to the corresponding schema properties for richer, more accurate output.

Tip

If your CMS collection has a defined author field, map it to the schema author property in the per-page schema settings. This produces author-attributed rich results in Google Search, which increases content credibility signals.

Regenerating schema

You can regenerate schema for any page at any time. Click the page in the Schema tab and click Regenerate with AI. This creates a new AI draft and replaces the previous schema stored for that page.

Regenerating is useful when you update your Personalization settings, change your brand name or description, or add new information you want reflected in your schema. Manual edits made to the previous schema are not preserved on regeneration.

Frequently asked questions

How many AI credits does schema generation use?
Each AI schema generation uses 1 credit per page. Generating schema for 10 pages costs 10 credits. You can view your remaining credits in the RankFrame dashboard under your account.
What happens if my Personalization settings are incomplete?
RankFrame will still generate schema, but the output may contain placeholder values for fields like business description, social profiles, or contact details. Fill in your Personalization settings before generating for best results.
Can I regenerate schema for a page after editing it?
Yes. Click Generate with AI again at any time. The new output will replace the previous one. Any manual edits you made to the existing schema will be overwritten, so regenerate only when you want a fresh AI draft.
Does AI generation work for CMS collection pages?
Yes. RankFrame reads CMS collection items from your Framer sitemap. AI generation creates schema for each individual collection item using the page title and URL. For richer schema on CMS pages, map CMS fields to schema fields in the per-page schema settings.
Can I generate schema in bulk for all pages at once?
Yes. From the Schema tab, select all pages and click Generate with AI. RankFrame will process each page sequentially, using one credit per page. You can review and edit individual pages after bulk generation completes.
