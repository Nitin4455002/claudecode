RankFrame Redesign · Section 01

Onboarding

Plugin-first. A new user installs RankFrame inside Framer and lands here. Account is created with Google OAuth, the trial requires a card up front, the current Framer site auto-connects, personalization is captured per website, and the user lands on Global Settings.
