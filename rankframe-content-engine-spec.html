Provider setup checklist (engineering)
  1. Anthropic API. Add ANTHROPIC_API_KEY. Use model claude-sonnet-4-6 for drafts/rewrites, claude-haiku-4-5-20251001 for alt text + quick AI actions. Enable prompt caching on system prompt (5k+ tokens of brand voice + style guide).
  2. DataForSEO. Add DATAFORSEO_LOGIN + DATAFORSEO_PASSWORD. Use Keywords Data API for volume, SERP API for top-10. Wrap responses in a 30-day Redis cache keyed by normalized keyword + locale.
  3. Firecrawl. Add FIRECRAWL_API_KEY. Call only during research step, never during draft generation. Cache extracted content by URL hash for 7 days.
  4. Voyage AI. Add VOYAGE_API_KEY. Model voyage-3. Embed each Framer site's pages on first connect, re-embed on weekly cron or webhook from Framer plugin.
  5. Framer Plugin API. No key needed, runs inside the plugin context. Sync server gets a short-lived auth token from the plugin to identify the user and target site.
  6. Credit accounting. Wrap every provider call in a single chargeCredits(team_id, action, credits) middleware that fails closed if balance is insufficient. Log to credit_ledger table atomically with the action result.
  7. Scheduled publish worker. Cron every 5 min: query content_drafts WHERE scheduled_at <= now() AND status = 'approved' AND framer_cms_item_id IS NOT NULL, call Framer plugin sync endpoint to flip draft: false, mark status = 'published'.
