Alt text is one of the most overlooked ranking signals on Framer sites. Framer is a design-first platform. Its users build visually rich websites packed with hero images, screenshots, portfolio photography, icons, and infographics. Those images often carry more meaning than the surrounding copy. Yet every image that ships without descriptive alt text is invisible to search engines and inaccessible to screen reader users.

The problem is compounded by how Framer handles alt text natively: one image at a time, in the canvas editor properties panel. There is no audit view to see which images are missing alt text, no bulk editing workflow, and no AI assistance. For a site with 80 or 100 images, adding alt text manually to each one is hours of repetitive work that most Framer designers skip entirely.

This guide covers what alt text is, why it matters for both SEO and accessibility, exactly how Framer handles alt text today, where the native tooling falls short, and how to use RankFrame to audit and bulk-generate alt text across your entire Framer site, including CMS collection images, in minutes.

What Is Alt Text and Why It Matters

Alt text (alternative text) is an HTML attribute added to image elements that provides a text description of the image content. Here is what it looks like in the rendered HTML of a Framer page:

<img src="hero-dashboard.jpg" alt="RankFrame SEO audit dashboard showing a site score of 87 out of 100" />

That single attribute serves three distinct purposes that all have measurable impact on your site's performance.

1. Search Engine Understanding

Search engines cannot see images. They read alt text to understand what an image depicts, which informs how they index the page and whether the image appears in Google Image Search results. Images are a significant discovery channel: Google Images generates billions of searches per month, and a well-optimized image can drive traffic that text-only content never would. For Framer sites where a hero image or product screenshot is the primary visual statement on a page, alt text is the only way that image contributes to keyword relevance.

2. Accessibility Compliance

Screen readers used by blind and low-vision users read alt text aloud when they encounter an image. Without alt text, users relying on assistive technology hear "image" or the raw filename, such as "IMG_4821.jpg." This is a failure of both usability and legal compliance. WCAG 2.1 Success Criterion 1.1.1 (Non-text Content) requires that all meaningful images have a text alternative. Many jurisdictions, including the European Union under the European Accessibility Act and the United States under the ADA, hold websites to accessibility standards. An alt text audit is therefore both an SEO practice and a compliance exercise.

3. Fallback Content

When images fail to load, browsers display the alt text in place of the image. This matters in low-bandwidth environments and for users on slow connections. Displaying a meaningful description rather than a broken image icon keeps the page functional and informative.

Quick Definition Alt text is not the same as an image title, caption, or filename. It is the alt attribute specifically. Each of these serves a different purpose. Alt text is the one that directly affects screen reader output, search engine image indexing, and broken-image fallback display.

How Framer Handles Image Alt Text Natively

Framer gives you two ways to set alt text natively, neither of which scales well for large sites.

Per-Image in the Canvas Editor

The primary method is selecting an image element in the Framer canvas and typing alt text directly into the Alt Text field in the right-side properties panel. This is intuitive for adding alt text to a single hero image or logo, but it requires you to click on every image in your project individually, remember to do it for every page, and repeat the process when new images are added.

For a typical Framer marketing site with 5 to 7 pages, a conservative image count might look like this: hero image, 3 feature screenshots, 2 team photos, 8 logos, 4 blog thumbnail images, 6 testimonial author photos, a footer illustration. That is already around 25 images, and many Framer sites have far more.

Screenshot: Framer canvas editor with an image selected and the Alt Text field visible in the right properties panel

Asset Manager (Cmd+K)

The Framer Asset Manager, opened with Cmd+K (Mac) or via the Assets panel, lists all images in your project in one place. This is the closest Framer comes to a bulk alt text view. You can click on an image in the Asset Manager and edit its alt text without having to find the element in the canvas. However, the Asset Manager does not show you which images are missing alt text, does not flag gaps, and does not provide any automation or AI assistance. It is a viewing tool, not an audit or generation tool.

Screenshot: Framer Asset Manager panel showing a list of project images

CMS Image Alt Text via Field Variables

For sites using Framer CMS, images inside CMS collection items can have alt text bound to a CMS text field. You add a text field to your collection (for example, "Image Alt Text"), type the alt text for each collection item, and then bind the image component's alt attribute to that field variable. This works correctly, but it requires manually writing alt text for every CMS item and setting up the binding correctly in the collection template. There is no automation or bulk writing assistance.

The Core Limitation

Framer's native alt text tooling has no audit view to show missing alt text across the site, no AI generation, no bulk operation beyond what the Asset Manager provides one-by-one, and no CSV export for review or client sign-off. For any site with more than a handful of images, this means alt text is almost always incomplete.

Common Scenario A Framer design studio launches a new portfolio site with 60 canvas images and 40 CMS project images. All 100 images ship with no alt text because the designer focused on visual quality, not alt attribute fields. That site is indexed by Google with 100 invisible images. Every one of those images is a missed keyword and missed image search opportunity.

Why Missing Alt Text Hurts Framer Sites

The impact of missing alt text is not theoretical. It manifests in measurable SEO and accessibility outcomes, and design-heavy Framer sites are disproportionately affected compared to text-heavy sites like blogs or news outlets.

72+ Missing Alt Texts Is Common on Design-Heavy Portfolios

A typical Framer portfolio or SaaS landing page built by a designer prioritizes visual impact. These sites often have more pixel area covered by images than by text. It is common to find portfolios with 50 project images, 20 UI screenshots, 10 icon images, and a scattering of logos and texture photos. Running an image SEO audit on such a site routinely surfaces 70 to 100 images without alt text.

Each missing alt text is a missed opportunity for Google to understand the page's visual content. On a portfolio page for a "brand identity design agency in New York," a project image without alt text is invisible. With alt text reading "Brand identity design for Brooklyn coffee roaster including logo, packaging, and signage," that image contributes to the page's relevance for related searches.

Accessibility Compliance (WCAG)

WCAG 2.1 Level A requires that all non-decorative images have meaningful alt text. This is not optional for any site aspiring to professional quality. Government sites, educational institutions, and increasingly commercial sites in regulated industries face legal exposure for WCAG non-compliance. Even outside those industries, accessibility failures damage brand reputation when discovered. A creative agency with an inaccessible portfolio site sends a poor signal about its attention to quality.

Image Search Ranking

Google Image Search is a meaningful traffic source for visual industries. Photographers, architects, interior designers, UI designers, and product companies all benefit from image search traffic. Google explicitly states that alt text is a primary signal it uses to understand image content and determine relevance for image search queries. Without alt text, your images do not appear for any search query regardless of visual quality.

Crawl Context for Text-Light Pages

Many Framer landing pages are intentionally copy-light. A single headline, a subheadline, a short feature list, and several large images may be the entire content of a page. When images carry this much of the page's communication, their alt text becomes critical context for Google's understanding of the page's topic. A page with two sentences of body text and 10 images, all missing alt text, gives Google almost nothing to work with for keyword relevance assessment.

The Compound Effect Adding alt text to 80 previously unoptimized images does more than improve image search performance. It enriches the textual context of every page those images appear on, which improves the page's relevance signals for its target keywords across all search results, not just image search.

Writing Good Alt Text: Guidelines and Examples

Even with AI generation, understanding what makes alt text effective helps you evaluate and refine the output. Here are the principles that separate high-quality alt text from filler descriptions.

Be Specific and Descriptive

Alt text should describe what is actually in the image with enough specificity to convey meaning. Vague descriptions like "photo of a person" or "screenshot of a tool" communicate nothing useful to search engines or screen readers. Specific descriptions like "Product manager reviewing a sprint board in a Framer-built project management dashboard" provide genuine context.

Keep It Under 125 Characters

Screen readers typically truncate alt text at around 125 characters. Aim to communicate the most important information within that limit. If an image is complex (such as an infographic), consider also providing a longer description in the surrounding page copy or a linked text alternative.

Include Keywords Naturally, Not Forcefully

Good alt text describes the image. If your target keyword naturally fits the description, include it. If it does not fit naturally, do not force it. "Framer SEO dashboard showing keyword position history and impressions" is natural. "Framer SEO keyword rank track optimize Google" is keyword stuffing and will be treated as spam. Google is explicit that keyword stuffing in alt text can result in a manual penalty.

Do Not Start with "Image of" or "Photo of"

Screen readers already announce that the element is an image. Beginning with "image of" wastes characters and creates redundancy. Go straight to describing the content: not "Image of a woman using a laptop" but "Designer reviewing color palette options in Framer on a MacBook."

Use Empty Alt for Decorative Images

Images that are purely decorative, such as background textures, abstract shapes, gradient overlays, or decorative dividers, should have an empty alt attribute: alt="". This tells screen readers to skip the image entirely, which keeps the listening experience clean. Do not leave the attribute out entirely, as some screen readers will then read the filename. Set alt="" explicitly.

Do: Effective Alt Text

  • "Brand identity design for a New York coffee roaster including logo, packaging, and signage"
  • "RankFrame SEO audit showing a site score of 82 with three red zone issues flagged"
  • "Architect's exterior render of a modernist family home with floor-to-ceiling windows"
  • "Team of four designers collaborating over wireframes in a bright Shoreditch studio"
  • "Google Search Console keyword impressions chart showing upward trend over 28 days"

Don't: Poor Alt Text

  • "image"
  • "photo.jpg"
  • "Our work"
  • "SEO Framer SEO plugin SEO optimization"
  • "Image of a screenshot showing our product"
  • Leaving alt text empty on a meaningful image
  • Using the same alt text for multiple different images

Match Alt Text to Page Context

The same product photo might appear on different pages with different contexts. On a product page for a specific camera lens, the alt text might focus on the product model and its key feature. On a photography blog post about low-light techniques, the alt text for the same lens image should reflect its role in that context. Alt text is not universal metadata attached to an image; it is page-level description that should reflect where and why the image appears.

Alt Text Strategy for Different Framer Site Types

The approach to writing and generating alt text should vary by site type because the images on different types of Framer sites serve different purposes and carry different SEO weight.

Portfolio and Design Studio Sites

For a design portfolio, images are the primary content. The alt text should describe the work shown: the type of project, the brand or client if publicly attributable, the design elements visible, and the deliverable type. A brand identity project image might read: "Brand identity system for a Copenhagen sustainable furniture brand including logo, wordmark, and business card design." This alt text targets both image search queries from potential clients looking for similar work and text search queries for related design services.

When using RankFrame's AI generation on portfolio images, review the output carefully. AI can describe a logo as "logo design on white background" where a human writer would recognize it as "minimalist geometric wordmark for a Nordic architecture firm." Supplement AI output with industry-specific details where the AI does not have enough context.

Screenshot: RankFrame Image SEO panel showing a portfolio site with CMS project images listed, several with red dot indicators

SaaS Landing Pages

SaaS Framer sites rely heavily on product screenshots, interface mockups, and feature illustration graphics. Alt text for these images should describe the UI functionally: what the screen shows, what action is being taken, what the feature illustrates. "Framer drag-and-drop CMS editor with a blog post open and the SEO settings panel visible" describes the screenshot in a way that is useful both for accessibility and for capturing informational search queries from users researching Framer CMS capabilities.

Avoid generic SaaS alt text like "dashboard screenshot" or "product interface." These contribute nothing. The goal is to make each screenshot legible as a text description to someone who cannot see the image.

Blog and Content Sites

Framer blogs typically include featured images, inline diagrams, chart screenshots, and author photos. For diagrams and charts, the alt text should communicate the main conclusion or data point the visualization shows. "Bar chart comparing organic search traffic growth for three Framer sites over 6 months, with sites using schema markup growing 40% faster" is far more useful than "bar chart."

For featured images that are illustrative rather than informative (abstract backgrounds, decorative headers), use empty alt text rather than forcing a description of decorative content.

E-Commerce and Product Sites

Product images require alt text that identifies the product specifically: model name, color, key differentiating feature, and any relevant context. "Handmade leather messenger bag in dark cognac with brass hardware and adjustable strap" serves both image search and the accessibility need to communicate what is being shown. For product images in multiple colors or configurations, each variant should have alt text that reflects the specific variation shown.

Agency and Freelancer Sites

Agency sites typically mix portrait photos (team, clients), office photos, project work images, and decorative brand elements. Team portrait alt text should follow a consistent format: "First Name Last Name, Role at Company Name." Client logos should read "Client Company Name logo." Office photos can describe the environment: "7 Seers creative studio workspace in Lucknow with team members at standing desks." Decorative texture or background images should use empty alt text.
