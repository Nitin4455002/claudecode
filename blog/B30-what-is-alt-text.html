What is Alt Text? Why It Matters for SEO and Accessibility (2026)

By RankFrame Team  ·  Updated May 2026  ·  14 min read

Alt text, short for alternative text, is a written description of an image that lives inside the image's HTML alt attribute. It is read aloud by screen readers for visually impaired users, displayed when the image fails to load, and used by search engines to understand what the image depicts. Alt text is one of the highest-leverage on-page SEO improvements you can make and the single most important accessibility requirement for images. This guide explains what alt text is, how to write it well, the difference between alt text and similar attributes, and how to audit and bulk-generate alt text on a Framer site.

What is Alt Text?

Alt text is the value of the alt attribute on an HTML <img> element. It is a text alternative that describes the image's content and function for users and machines that cannot see the image. The full syntax in HTML looks like this:

<img src="golden-retriever-puppy.jpg" alt="A golden retriever puppy sitting in a field of yellow dandelions" />

The string "A golden retriever puppy sitting in a field of yellow dandelions" is the alt text. It does three jobs:

  • Screen readers announce it to visually impaired users so they can understand what the image shows.
  • Search engines read it to index the image and connect it to relevant queries.
  • Browsers display it as fallback text if the image file fails to load (slow connection, broken URL, blocked by content blocker).

The alt attribute itself is required on every <img> element by the HTML specification. The value can be a descriptive string for informative images, or an empty string (alt="") for purely decorative images that should be skipped by screen readers. What is never acceptable is omitting the attribute entirely.

Why Alt Text Matters for Accessibility

Roughly 2.2 billion people worldwide live with some form of vision impairment, according to the World Health Organization. Many use screen readers like JAWS, NVDA, VoiceOver, or TalkBack to navigate the web. When a screen reader encounters an <img> element, it reads the alt text aloud. Without alt text, the user either hears the image file name (which often looks like "IMG_4382.jpg," providing zero useful information) or nothing at all, leaving a gap in the page's meaning.

WCAG 2.1 Success Criterion 1.1.1 (Non-text Content)

The Web Content Accessibility Guidelines (WCAG), maintained by the W3C, are the international standard for web accessibility. Success Criterion 1.1.1, "Non-text Content," requires that all non-text content (including images) have a text alternative that serves an equivalent purpose. This is a Level A requirement, the most basic level of accessibility compliance.

Legal compliance: ADA and EU accessibility laws

Web accessibility is increasingly a legal requirement, not just a best practice:

  • United States: The Americans with Disabilities Act (ADA) has been interpreted by US courts to apply to commercial websites. Lawsuits over inaccessible websites have grown rapidly each year. WCAG 2.1 Level AA is the de facto compliance standard.
  • European Union: The European Accessibility Act came into force in June 2025, requiring most consumer-facing digital services to meet WCAG 2.1 Level AA. Non-compliance can result in significant fines.
  • United Kingdom: The Equality Act 2010 requires reasonable accessibility accommodations on UK websites.
  • Canada: The Accessible Canada Act and provincial laws like the AODA (Ontario) require WCAG-aligned accessibility.

Missing alt text is one of the most commonly cited issues in accessibility lawsuits and audits because it is easy to detect with automated tools and undeniably violates WCAG 1.1.1. Adding alt text is the single fastest improvement you can make to reduce legal exposure and serve disabled users.

Accessibility benefits everyone Screen reader users are the primary beneficiaries of alt text, but they are not the only ones. People with slow internet connections see alt text when images fail to load. Users on text-only browsers, voice assistants, and accessibility-focused mobile setups all rely on alt text. Writing good alt text is an investment in usability for a much larger audience than the disabled-only count suggests.

Why Alt Text Matters for SEO

Search engines cannot "see" images the way humans do. While Google's image recognition has improved dramatically through computer vision, the alt text remains the most reliable signal Google uses to understand what an image depicts and how it relates to the surrounding page content.

Google Image Search ranking

Google Image Search drives substantial referral traffic for many sites, particularly those with visual content like products, recipes, infographics, and design portfolios. Pages with descriptive, accurate alt text rank better in Google Image results for related queries. A product page with alt text "blue running shoes for women size 8" can appear in image searches for that exact query, sending users directly to the product.

Topical relevance for the parent page

Google reads alt text as part of the page's overall content. A page with images that have alt text mentioning the page's topic reinforces topical relevance and can help the page itself rank better for text-based queries, not just image queries.

Fallback when images fail to load

When an image fails to load, browsers display the alt text in place of the broken image. This preserves the meaning of the page for any user, indexer, or accessibility tool that cannot retrieve the image at that moment. Without alt text, a broken image is just empty space.

Documented as a Google ranking signal

Google has publicly stated multiple times in its Search Central documentation that descriptive alt text helps Google understand image subject matter and is one of the few image attributes the crawler explicitly looks at. Unlike many SEO claims, this is officially confirmed rather than inferred.

How to Write Good Alt Text

Effective alt text follows a few simple rules:

Be specific and descriptive

Describe what the image actually shows in enough detail that someone who cannot see the image gets the same information as someone who can. "Dog" is too vague. "Golden retriever puppy sitting in a field of yellow dandelions" is specific.

Include keywords naturally

If the image relates to a keyword you want the page to rank for, include that keyword in the alt text in a natural way. Do not stuff multiple keywords or write alt text that reads like a meta keywords list. Keyword stuffing in alt text is treated by Google the same way as keyword stuffing anywhere else: it can trigger algorithmic penalties.

Keep it under 125 characters

Most screen readers cut off alt text at around 125 characters. Aim for one descriptive sentence. If an image needs more explanation than 125 characters allow, the additional information probably belongs in a caption or in body text near the image, not in the alt attribute.

Do not start with "image of" or "picture of"

Screen readers already announce the element as an image before reading the alt text. Starting with "image of" or "picture of" is redundant and wastes characters. Start directly with the description.

Consider context

The same image can warrant different alt text on different pages. A photo of a coffee cup on a cafe homepage might get "espresso in a white ceramic cup on a wooden cafe table." The same photo on a product page for the cup might get "white ceramic espresso cup, 6 ounce capacity, dishwasher safe." The alt text should reflect why the image is on this specific page.

Decorative images get empty alt

Background patterns, dividers, decorative icons, and any image that adds no informational value should use alt="". This explicitly tells screen readers to skip the image. Adding meaningless alt text like "decoration" or "background" to such images creates noise for screen reader users without providing any benefit.

Examples of Good vs Bad Alt Text

The same image can have wildly different alt text quality depending on how it is written. Here are common scenarios with paired examples:

Image Bad alt text Good alt text
Product photo of a leather wallet alt="wallet" alt="Brown leather bifold wallet with embossed initials, open to show six card slots"
Photo of a chef plating pasta alt="image of chef cooking" alt="Chef garnishing a plate of spaghetti carbonara with fresh black pepper"
Logo of a company called Acme Corp alt="logo" alt="Acme Corp logo"
Decorative geometric pattern in a hero section alt="background pattern" alt=""
Screenshot of a dashboard for a SaaS product page alt="screenshot" alt="RankFrame dashboard showing keyword rankings, page audit scores, and indexing status for a Framer site"
Infographic showing five steps in a process alt="infographic" alt="Five-step SEO process: keyword research, on-page optimization, technical audit, content publishing, and backlink building"
Stock photo of a smiling team in an office alt="team meeting business marketing strategy SEO website" alt="Marketing team reviewing analytics on a laptop in a conference room"

Notice that the bad examples fall into recognizable patterns: too vague ("wallet"), redundant ("image of"), keyword stuffed (the team meeting example), or filler text on a decorative image (the geometric pattern). The good examples are concrete, specific, and free of redundant phrases.

Decorative Images and Empty Alt

Not every image on a page is informative. Many images exist only for visual interest: a subtle gradient in a hero section, a divider line between sections, a small icon next to a text label that already says the same thing. These are decorative images, and they should use empty alt text:

<img src="hero-gradient.png" alt="" /> <img src="divider.svg" alt="" /> <img src="email-icon.svg" alt="" /> Contact Us

In the third example, the icon next to "Contact Us" adds visual support but the text label already conveys the meaning. Adding alt text like "email icon" would cause a screen reader to announce "email icon, Contact Us," which is verbose and slightly confusing. Empty alt text lets the screen reader skip the icon and read just "Contact Us," matching what a sighted user perceives.

Empty alt is not the same as missing alt alt="" is an explicit signal that the image is decorative and should be skipped. Missing the alt attribute entirely (no alt at all on the img tag) causes screen readers to fall back to reading the file name or the URL, which is almost always worse. Always include the alt attribute, even when its value is empty.

Where to Add Alt Text

In raw HTML

Add the alt attribute directly to the <img> tag:

<img src="/images/product.jpg" alt="Wireless noise-cancelling headphones in matte black" />

In CMS image fields

Visual builders and CMS platforms (Framer, WordPress, Webflow, Shopify, Wix, Squarespace) expose an Alt Text or Image Description field in the image properties panel. The platform writes the alt attribute to the rendered HTML for you. The location of the field varies:

  • Framer: Select an image element on the canvas; the right-side properties panel shows an Alt Text field.
  • WordPress: The media library Edit Image screen has an Alternative Text field. Block editor image blocks also expose an Alt Text field in the right sidebar.
  • Webflow: Select an image element; the Settings panel on the right has an Alt Text field with options for Custom, Alt Text from URL, or Decorative.
  • Shopify: Each product image has an Edit Alt Text option in the product editor.

In CMS collection items

For dynamic CMS content (blog posts, products, case studies), add an Alt Text field to each image field in your collection schema. Bind the alt attribute on the image component to that CMS field so each item provides its own alt text rather than inheriting a generic default.

Alt Text vs Title Attribute vs Filename

Three image-related attributes are often confused. Each serves a different purpose:

Attribute Purpose SEO impact
alt (alt text) Text alternative for screen readers and image-load failures. Required on every img element. High. Direct ranking signal for image search and topical relevance.
title (title attribute) Tooltip text shown when a user hovers their mouse over the image. Optional and rarely necessary. Minimal. Not consistently read by screen readers, not visible on touch devices.
File name (the image src filename) The actual file name of the image, e.g. blue-running-shoes.jpg. Minor. Google reads file names as a weak signal. Use descriptive hyphenated names rather than IMG_4382.jpg.

The title attribute is largely cosmetic. It provides a tooltip on hover, which mobile users never see (no hover) and screen readers usually ignore in favor of alt text. Most accessibility guidelines explicitly recommend not relying on title for any essential information.

File names should be descriptive but not stuffed. blue-running-shoes-women.jpg is good. IMG_20240315_182340.jpg is bad. blue-running-shoes-best-running-shoes-2026-cheap-running-shoes-women.jpg is keyword stuffing and looks spammy.

How to Audit Alt Text on a Site

Manually checking alt text on every page is impractical for any site with more than a handful of pages. Use automated tools to catch missing or low-quality alt text at scale.

Google Lighthouse

Lighthouse, built into Chrome DevTools, includes an Accessibility audit that flags every image missing an alt attribute. Open DevTools (right click, Inspect), click the Lighthouse tab, check Accessibility, and run the audit. The report lists every img element on the current page that lacks alt text. Lighthouse is free and runs locally.

axe DevTools

axe DevTools is a free Chrome and Firefox extension from Deque Systems that runs the same accessibility tests used by enterprise accessibility teams. It catches missing alt text, empty alt that should be descriptive, and decorative images that should have empty alt but do not. axe is generally considered the gold standard for in-browser accessibility testing.

WAVE

WAVE (Web Accessibility Evaluation Tool) by WebAIM provides a visual overlay on any web page showing accessibility issues directly on the page. Missing alt text appears as a red icon on the affected image. Available as a Chrome extension and as a free web tool at wave.webaim.org.

Chrome DevTools Elements panel

For ad-hoc spot checks, the Elements panel in Chrome DevTools lets you inspect any image element and read its alt attribute directly. Useful when investigating a specific image you suspect is missing alt text.

Screaming Frog and other crawlers

For full-site audits across hundreds or thousands of pages, a site crawler like Screaming Frog SEO Spider scans every page, lists every image, and reports the alt attribute (or its absence) for each one. Filter by "missing alt text" or "alt text over 100 characters" to find specific problems quickly.

If You Have a Framer Site

Framer provides an Alt Text field on every image component placed on the canvas. To set alt text manually, select the image element, open the right-side properties panel, scroll to the Accessibility section, and type your alt text into the Alt Text field. Framer writes this value to the rendered HTML's alt attribute automatically. For decorative images, leave the Alt Text field empty and Framer outputs alt="".

For CMS images, the same Alt Text field exists on the Image component inside your collection template, with the option to bind it to a dynamic CMS field. Add an Alt Text field to your CMS collection schema and bind the image component's Alt Text property to that field using the variable picker. Each collection item then provides its own unique alt text.

The bulk audit problem

Framer's per-image Alt Text field is straightforward for a handful of images on a few pages. The problem is scale. A typical Framer site has dozens or hundreds of images spread across canvas pages and CMS collections. Manually auditing every image to confirm alt text is present, descriptive, and unique is impractical inside the Framer editor, which has no list view of all images on the site, no missing-alt warning, and no way to edit alt text in bulk.
