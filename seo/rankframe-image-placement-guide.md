All paths are relative to the unzipped `RankFrame/` folder.

## Tips

- Insert images **after** the relevant heading/paragraph, not inside it
- After inserting, click the image and adjust alt text (Framer prompts for it) — use the filename or section name as alt text
- For multi-image schema docs (Article, Book, etc.), keep the order top-to-bottom matching how the fields appear in the plugin
- If a section heading in this guide doesn't match exactly, place the image at the closest matching section
