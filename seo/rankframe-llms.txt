# RankFrame

> RankFrame is the first comprehensive SEO plugin built natively inside Framer. It unifies schema markup, Google indexing, image SEO (bulk AI alt text), keyword tracking, page speed audits, and 404 monitoring inside the Framer editor — no separate SEO tool, no embed codes.

RankFrame is a Framer-marketplace plugin made by 7 Seers. It runs entirely inside the Framer editor and ships SEO features that previously required stitching together multiple tools (Yoast, Screaming Frog, Search Console, Schema.dev, etc.). Plans: Personal $15/mo or $108/year (1 website, all features) and Agency $40/mo or $288/year (unlimited Framer sites, every Personal feature included). Yearly billing saves 40% on both. A 7-day free trial is available — every limitation is lifted the moment you subscribe.
